## Critical — block Plan 2

Plan 2 opens the doors C2 fails to guard and feeds them goals generated by a model, which is when
C3's open dict and I1's unescaped literals stop being latent.

### ✅ C1. The purity guard did not enforce invariant 1
`tests/test_purity.py` · fixed in `f043a1a`

`BANNED_PREFIXES` held only third-party names and the AST walk saw only import statements, so a
pure package could `import urllib.request, socket, http.client` and exfiltrate freely, or reach
anything through `__import__("openai")` / `importlib.import_module("httpx")`. All of it passed.

CLAUDE.md sells telemetry safety as *structural* — "the pure packages cannot import an HTTP
client, so telemetry can only live in `mendel-api`". That claim was false.

**Fix applied:** ban stdlib transports (`urllib`, `http`, `socket`, `ssl`, `ftplib`, `smtplib`,
`telnetlib`, `asyncio`, `xmlrpc`, `webbrowser`) and flag `ast.Call` to the dynamic importers.
Verified against a fixture using four of them — five violations named.

**Not done, deliberately:** inverting to an allowlist. `mendel-compiler` legitimately needs
`subprocess` to run Nextflow, so whether `subprocess` counts as a transport is a design question
rather than a bug fix. See D1.

### ✅ C2. The egress guard stops at the first model boundary
`tests/test_egress.py`, `comeni_core/egress.py`, `comeni_core/ir.py`, `comeni_core/decision.py` · fixed in `8ad4153`

All four guard tests walk `typing.get_args`, which returns `()` for a nested `BaseModel`. Nothing
inspects inside `RepairRequest.ir` or `PublishBundle`. The shipped payloads **already** carry what
invariant 14 forbids:

| Field | Problem |
|---|---|
| `ResolvedValue.value: Any` | `Any` in a payload |
| `ResolvedValue.reason: str` | undeclared free text |
| `PipelineIR.decisions: list[Any]` | `Any` in a payload |
| `DecisionRecord.candidates / chosen / human_override: Any` | `Any` in a payload |
| `DecisionRecord.reason: str` | undeclared free text |

Reproduced: a `RepairRequest` serialises a patient path, a consultant's name and an SSN, and
`tests/test_egress.py` reports 7 passed.

This is the `user_note: str` hole that commit `0f1986b` claims to close. It was closed at depth 0
only. `PublishBundle` is the door with no undo.

**Fix designed:**
1. `_payload_types()` expands nested `BaseModel` fields transitively with a seen-set; offenders
   report as `Outer.field -> Inner.field`.
2. That makes the shipped payloads fail, which is the point. Eliminate the `Any` fields rather
   than allowlist them: `ResolvedValue.value` and `DecisionRecord.candidates/chosen/human_override`
   become a closed scalar union; `PipelineIR.decisions` becomes `list[DecisionRecord]`, which needs
   `Tier`/`ReviewLevel` moved to a shared module to break the `ir` ↔ `decision` import cycle.
3. The genuine free-text carriers (`ResolvedValue.reason`, `DecisionRecord.reason`) get **named**
   in `FREE_TEXT_FIELDS`. Forcing the admission is the design; hiding them is not.

`Ambiguity.context: dict[str, Any]` needs nothing — `Ambiguity` is not reachable from any payload.

**Do not fix by exempting nested models. That is the hole.**

### ✅ C3. `Goal.constraints` is an open `dict[str, Any]`
`mendel_resolver/goal.py`, `resolve.py` · fixed in `2873297`

Reproduced: a goal containing

```yaml
constraints:
  seq_platform: /data/patients/PT-4471023/S1_R1.fastq.gz
```

emits `params.star_align_seq_platform = '/data/patients/PT-4471023/S1_R1.fastq.gz'` into `main.nf`
and `pipeline.ir.json`, labelled **tier 1 structural, review `none`** — and the build reports
**`0 requiring review`** where it otherwise reports 1. The injected value replaced a tier-4 flag.

Invariant 15 says no input accepts a sample identifier, filename or path. It does.
`test_goal_has_nowhere_to_put_a_sample_identifier` gives false assurance: `Goal(samples=[...])`
raises while `Goal(constraints={"sample_id": ...})` validates fine. There is zero test coverage of
the constraints path.

**Fix designed:** close `constraints`. `required_states` becomes a first-class `Goal` field — it is
already magic-keyed in `router.py` — and parameter overrides become
`list[ParamOverride(name, value)]` over a closed scalar union, validated against declared contract
parameters. See D2 for the tier question, which is separate.

### ✅ C4. Edges keyed on `type_id` alone — featureCounts wired to the `.bai`
`mendel_resolver/resolve.py` · fixed in `f043a1a`

`produced` was a dict keyed on `type_id`, overwritten by every producing node, and consumers
matched on type without checking `port.state_required`. With `samtools/index` in the graph,
featureCounts received the index file:

```groovy
SUBREAD_FEATURECOUNTS(SAMTOOLS_INDEX.out.bai.combine(ch_gtf.map { it[1] }))
```

Valid Nextflow, no flag, no decision record — and `-stub-run` structurally cannot catch it,
because nf-core stubs never read their inputs. The product claim inverted: something was guessed,
it was wrong, and it was silent.

**Fix applied:** sources are a list; a consumer takes one whose emitted states satisfy its port;
among those the **smallest surplus** wins, reusing `router.py`'s existing producer-ranking rule.
Two equally good sources emit a tier-4 `DecisionRecord`. Verified: the build now emits
`SUBREAD_FEATURECOUNTS(SAMTOOLS_SORT.out.bam…)`.

**C4 remainder, now fixed:** `samtools-index` produced `alignment.bam[coordinate_sorted, indexed]`. An index is not a BAM, and the modelling is a lie the
router is entitled to believe. It declares a distinct `alignment.bai` type now — nf-core's `SAMTOOLS_INDEX` emits `bai`/`csi`/
`crai` and no BAM at all, so there was no honest passthrough output to declare either. A
multi-`want` regression test covers the case every pre-audit test missed.

## Minor

- `frozenset` fields outside `IREdge.states` serialise in hash order (`contract.py`, `goal.py`).
  Not in the byte-identical path today, but Plan 1.7's lockfile pins contract digests, which hash
  exactly these fields. Free to fix now, expensive later.
- `GoalInput` lacks `extra="forbid"` while `goal.py`'s docstring claims both models have it.
  `GoalInput(type_id=..., filename="PT-4471023_R1.fastq.gz")` succeeds and silently drops the key.
- `Registry.load` silently overwrites duplicate contract ids **within** one layer — no
  `ShadowRecord`, resolved by glob order. Cross-layer shadowing is carefully recorded; in-layer is
  invisible. Should raise.
- Doc-vs-reality: `make dev` / `make migrate` do not exist (Makefile has `test`, `lint`, `fmt`);
  `uv run forge …` does not exist; Plan 1 still says `modules/` lives at the repo root,
  contradicting `351a6ff`; CLAUDE.md's tier table states module choices carry a tier, which
  `IRNode` does not implement. Fix: split the Commands section by availability — *works today* /
  *Plan 2* / *Plan 3*.
- Two shipped rules can never fire — `subject: aligner` matches no contract parameter, and
  `then: {module: ...}` is ignored because `_resolve_param` reads only `then["value"]`. Documented
  in the rule-tables spec §2 and fixed by it. Until then: a comment in the YAML, and a test holding
  `KNOWN_DEAD_RULES` as a literal so a *third* one fails the day it appears and the set empties
  itself when the spec lands.
- `test_gates.py`'s first test is not skipped when nextflow is absent, so on a clean machine it
  fails for the wrong reason instead of skipping.
- `emit()` builds anonymous classes via `type("V", (), {...})()` for Jinja attribute access. The
  plan's own constraint says no dicts-as-models; this is that idea in disguise. Use a `NamedTuple`.
- Function-level `import re` in `emit.py` and `test_spine_contracts.py`.

## Decisions needed from the operator

- ✅ **D1 — decided: allowlist for the two closed packages.** `comeni-core` and
  `mendel-resolver` have closed allowlists; `mendel-compiler` keeps a banlist because it must run
  Nextflow via `subprocess`. Verified: `import os` and `import ctypes` are now caught, neither of
  which any banlist would have listed.
- ✅ **D2 — decided: `ResolvedValue.source`.** A tier says how well something was decided; source
  says who. Same shape as measured-versus-asserted in the profiling spec.
- ✅ **D3 — decided: a layer is a directory.** `--registry` points at a directory holding
  `contracts/`, `rules/` and `vocabularies/`; all three stack.
- *(superseded)* **D1 — allowlist or banlist for purity?** An allowlist is closed and shorter, but forces a ruling
  on `subprocess`, which `mendel-compiler` needs to run Nextflow and which can shell out to `curl`.
- **D2 — what tier is a goal-supplied parameter?** The reviewer argues tier 1 is dishonest because
  "no choice exists" is false when a human chose. Counter-argument: from Mendel's side no choice
  does exist, and a user who specifies a value has legitimately removed the ambiguity, so
  suppressing the tier-4 flag is correct *once the value can no longer be a path*. Closing the dict
  (C3) fixes the security problem either way; this is about honesty of labelling.
- **D3 — should `--registry` point at a layer directory?** Making vocabularies and rules stack
  (I4) means a layer is a directory containing `contracts/`, `rules/`, `vocabularies/`. That
  changes a documented flag, and it is also the shape the rule-tables spec §9 assumes.

## Confirmed strengths

- **Determinism survives adversarial testing.** The reviewer ran the full CLI under
  `PYTHONHASHSEED` 1, 2, 3 and 99999 — `main.nf` and `pipeline.ir.json` byte-identical every time.
  Every ordering point is deliberately sorted. **Caveat:** both determinism tests run in-process,
  so they cannot detect hash-seed dependence. The property is real; the test does not prove it. A
  subprocess run under a different seed would close that.
- `tests/test_spine_contracts.py` is the strongest testing in the repository — it checks
  hand-written claims against someone else's code on disk, which is verification rather than
  restatement.
- `NfInput`, and the `needs_review()` fix in `8464f68`.

## The pattern worth remembering

All three test-enforced invariants failed the same way: **the guard checks the surface it was
written against and stops at the first boundary.** Third-party imports but not stdlib. Top-level
fields but not nested models. Declared fields but not the open dict beside them.

"Break it on purpose" was the right instinct and it stopped one level too early every time — each
guard was broken in exactly the way it had just been built to catch, and passing that test was
taken as proof of the general property.

**The generalisation:** when a guard passes its own break-test, ask what shape of violation the
break-test *did not* have.
