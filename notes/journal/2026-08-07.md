## The finding behind the findings

**Nine of thirteen fixes moved a check out of a caller and into a type.** A guard in a caller
is a guard the next caller forgets. A2 is the pure case: invariant 15 was enforced inside
`mendel build`'s own re-route, so `mendel upgrade` — the one verb that reads a file a stranger
wrote — had no check at all.

That sentence is worth more to the next session than any individual fix, and it now has a
sibling that is sharper:

> **A guard that has never been watched failing may be inert, not merely weak.**

That is **A14**, written into the audit as critical and left open. Four instances in a day,
each a test that passed against code that was deliberately broken — and the fourth was found
by the operator asking a question rather than by any test:

1. `test_two_layers_sharing_a_basename_do_not_collapse` had been unable to fail since Plan 1.7.
2. Task 6's fixture used one resolver for two sites that defaulted opposite ways, so it agreed
   with whichever it was not testing.
3. The same edge test asserted over an empty loop.
4. **Tasks 7, 9 and 10 were each reported verified on `make check`**, which deselects
   `tests/test_counts.py` — the only tests that exercise the v1 criterion. Nothing was broken
   and running them took 44 seconds, so the cost was never the reason. There was a habit, and
   no command that made the full set easy to type.

(4) is why `make verify` exists and why `CLAUDE.md` now **names the four files** — `resolve.py`,
`router.py`, `rules.py`, `mendel_compiler/cli.py` — that require it. "Use judgement" is what
produced the problem.

**A14 closes when every guard in `tests/` has a recorded revert that was watched failing.**
Not when someone reads them and judges them sound; that is how they got written.

## The two tasks that did not survive contact

**Task 7 could not be implemented as written**, and finding out why turned up A15.

Step 4 asked for `ReviewLevel.ADVISORY` while *"tier stays 2"*. `review_level` is a
`computed_field` over the tier, and `_drop_computed` exists precisely so a stored one cannot
disagree with it. Step 1 then asked `needs_review()` to name the node, and that method lists
`REQUIRED` only, under a test named for the guarantee. The two steps contradicted each other
and both contradicted the types.

Rewriting it produced the rule that matters: **report displacement, not origin.**

- Provenance — *where did this module come from* — is recorded on **every** node, always,
  because a curator reading a bundle needs it without asking. A flag is the wrong shape for a
  question with an answer everywhere.
- The **flag** fires only when a lower layer offered something that lost. That is the
  invariant-11 event.

Flagging origin would put a notice beside every module an overlay supplies and bury the one
that rerouted the pipeline — the failure the plan's own Step 4 warned about, arrived at by the
route it warned against.

And while working out where provenance could live, `rules.py` turned out to have the same
defect with **no record at all**: `by_target[key] = decision` replaces a whole block. That is
A15. Invariant 11 says all four kinds of declared data stack; only contracts were being
watched, because A5 was found by reading `router.py` and nobody read `rules.py` for the same
thing. **The audit's coverage was the gap, not its reasoning.**

**Task 9's blocklist collided with a legitimate value.** `dual.bam` is port `bam` on node
`dual` — an internal pointer the resolver writes — and is character-for-character a filename.
No text rule separates it from `run.bam`. The plan said *narrow the rule, do not exempt the
value*; the narrowing that works is by **who writes the field**, not by what the value looks
like. `HumanParamValue` guards `human_override` and `ParamOverride.value`; the machine-built
fields are already rebuilt from registry candidates by A8's fix.

The conflation underneath is **A16**, recorded and deferred: `DecisionRecord.chosen` holds a
param value, a contract ID or an edge pointer depending on `subject`.

## Decisions

**`mendel publish` no longer writes a bundle when its gate fails.** Not in the task; found
while adding `PublishBundle.gate`. Publish ran *before* the gate, so `--gate test` wrote the
artifact, failed, and returned 1 — leaving on disk a bundle that had just failed the only gate
that checks wiring.

**Signing a bundle is [#16](https://github.com/comeni-project/Comeni-Labs/issues/16), not a
docstring.** A6's fix bans `bytes` on every payload, which forecloses `signature: bytes`. The
guard asserted detached signing as the answer; that is a federation position stated in a test
comment, so it became an issue instead.

**`CLAUDE.md` stops saying the pure packages *cannot* reach the network.** They *do not* —
which is what two partial guards support. A1 built a `telemetry.py` importing only allowlisted
names that shipped a `Goal` over TCP with the guard green. Cost-raising, not a proof, and the
file says so.

## Traps

- **`make check` is not verification.** It deselects the counts-matrix tests. Use `make verify`
  after touching `resolve.py`, `router.py`, `rules.py` or `mendel_compiler/cli.py`.
- **Report displacement, not origin.** A layer supplying something new is a lab using the
  system as designed; a layer replacing what a lower one said is the silent reroute.
- **Guard by who writes a field, not by what the value looks like.** A blocklist that has to be
  clever about `dual.bam` versus `run.bam` is a blocklist about to be wrong.
- **Provenance is recorded by the loader, never by the file.** `layer_of` is on `Registry` and
  `RuleTable`, not on `ModuleContract` or `Decision`: a contract is content-addressed, and a
  rule block carrying its own `from_layer` is a rule block that can lie.
- **A plan's pre-flight numbers are claims, not facts.** Two were wrong this session.
