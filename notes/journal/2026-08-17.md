**This entry exists for one job: to hand Plan 2 to a fresh agent working with the operator to
redesign it.** The operator's judgement, and the reason for this entry, is that the project has
**drifted far enough from the original Plan 2 that reworking it beats executing it.** What
follows is the evidence for that, assembled by checking the plan against the code rather than
against memory.

Read this, then [`notes/README.md`](../README.md) for ordering, then the two Plan 2 documents.
**Do not start executing them.**

## Why Plan 2 is a redesign and not an execution

`notes/plans/2026-08-02-mendel-ai-and-forge.md` and its addendum
`notes/plans/2026-08-13-plan-2-corrections.md`. The addendum's own framing is the problem: it
says *"most of Plan 2 is still correct"* and lists a countable set of moved types. **It was
verified against the tree at Plan 1.12, which is fourteen merged pull requests ago.**

**Nine things neither document mentions**, each checked by grep against both files:

| | why it matters to Plan 2 specifically |
|---|---|
| `AiProvenance` | the artifact's record of what models were wired |
| `ValueSource.MODEL` | where an adapter says a model settled a value |
| `MD0225` | **refuses exactly what Plan 2 will produce** — see below |
| `coded()` | every diagnostic must go through it |
| `emitted_by` | a new code must name its raising package |
| `declares:` | the shape of every file the forge drafts |
| `comeni-registry` | the forge's output goes to **another repository** |
| submodule | how that repository is consumed here |
| `mendel docs` | the forge could generate its own review pages |

### Three that block execution outright

**1. `MD0225` refuses every model-authored value on day one.**
`materialise.py:102` hardcodes `ai=AiProvenance(available=[], used=[])` — the artifact states
that no model was reachable. `MD0225` says *"a value records a model settled it, and the build
records that none was available"*. The moment an `LLMResolver` writes `source: model`, loading
refuses. Plan 2 predates the field and has no task for it. **This is a design question, not a
one-line fix**: something has to decide what the build knows about its own model access, and
where that is threaded from.

**2. The forge's output target no longer exists as described.** Plan 2's global constraints say
*"The forge writes to `proposals/`, never to `contracts/`. Only human approval moves a file
across that boundary."* Since comeni-registry#1 there **is no `contracts/` directory** — a layer
is files that declare themselves, arranged freely, and the public convention groups them under
`tools/<namespace>/<tool>/`. Since issue #46 the registry is a **separate repository** with its
own CI, licence and version. So "human approval moves a file across that boundary" is now a
cross-repository pull request, and invariant 2's approval step has to be redesigned around that.
This is the largest single piece of drift and it is architectural.

**3. A new diagnostic code must be *emitted*, not merely declared.**
`tests/test_diagnostics_ownership.py` holds both directions —
`test_every_emitted_code_is_declared` and `test_every_declared_code_is_emitted`. The forge
therefore **cannot reserve an `MF` band ahead of use**; each code must go through `coded()` and
name its raising package in `emitted_by` in the same change that makes it fire.

## What has *not* drifted, so the redesign does not start from nothing

Recorded deliberately — a handoff that only lists breakage teaches the reader to distrust
everything.

- **The ports are unchanged.** `AmbiguityResolver.resolve(ambiguity) -> Resolution` in
  `mendel_resolver/ports.py` is what Plan 2 declares, and the corrections file already
  re-verified it once.
- **The invariants Plan 2 exists to satisfy are untouched** — 2 (AI authors offline, humans
  approve), 3 (three declared runtime points), 4 (a tier-3 miss demotes, never calls a model),
  6 (tier 4 always flagged). These are the spec and they have not moved.
- **`ValueSource.MODEL` and `AiProvenance` were built *for* Plan 2**, on 2026-08-16 when A130
  closed. They are the truthful place an adapter writes, and they exist before the adapter does.
  That is the good kind of drift.
- **Determinism is still a test.** Whatever the redesign does, `--no-ai` must stay the lane CI
  runs, and it currently has nothing to switch off.

## Two documents to read before designing anything

**[`notes/specs/2026-08-13-the-rule-drafter.md`](../specs/2026-08-13-the-rule-drafter.md)** —
unscheduled on purpose, and `CLAUDE.md` says to read it **before building any part of the
forge**. Tier 3 is the differentiator and nothing currently produces tier-3 rules; the spec names
four hard prerequisites and the central risk.

**Issue #38's closing note**, in `CLAUDE.md`'s open-issues table. Its sharpest point survives the
issue: *the drafting question and the measuring question are the same one* — a contract has
`meta.yml` as ground truth and a measurement has no equivalent. Twelve measurements ship and
**five of the original six turned out to be assertion-only, including `strandedness`.** Nothing
writes a measurement. That is the forge's hardest problem and Plan 2 does not name it.

## How to work with this operator

Written down because it was learned the expensive way on 2026-08-16, and it is now a section of
`CLAUDE.md` — *"Stop and speak when the estimate breaks"*.

- **An estimate wrong by more than about double is a decision point, not a hill to climb.** Say
  the new number, say what changed, offer the choice.
- **Present decisions as choices with costs**, not as prose. A number and two options is a
  sentence, and it is the whole of what the operator needs to steer.
- **One diagnostic run that collects every failure beats ten patch-and-rerun cycles**, which also
  hide how large the remainder is.
- **Use `superpowers:brainstorming` before designing** and `executing-plans` to execute. Subagents
  are for review and design only — never to write implementation code.
- **Work in a worktree**, and note the entry below before you trust a digest from one.

## One thing to know before you build anything in a worktree

comeni-registry#2 found that **the layer digest had been the SHA-256 of the empty string for
every build made under `.worktrees/`** — which is where `CLAUDE.md` requires plans to run. A
dot-component filter judged on absolute paths matched every file in the layer, and hashing
nothing succeeds, so it failed silently while `make verify` stayed green.

Fixed in #60. It is recorded here because it is **the third appearance of one bug** —
`test_architecture.py` and `make drift` were the first two — and because the technique that
caught it is the one to reach for: *build the artifact in two places and diff it*, rather than
run the suite.
