## What round four found, shortest first

- **A70 (important) — `publish` certifies an unchecked `main.nf`.** When `pipeline.yml` has no
  `emitted:` block — a supported state for archived/hand-authored files — publish's divergence guard
  (`MD0213`/`MD0214`) short-circuits to a no-op, so it gates whatever `main.nf` is on disk and stamps
  the verdict. Reproduced: an unrelated `main.nf` certified at exit 0, its digest recorded as
  emitted. Found by the relaunched lifecycle reviewer (see below), which also re-verified A46–A48,
  A50, A51, A53 hold. The door with no undo.
- **A71–A75 (important/minor) — docs and the error surface.** Issue #18's GitHub body understates
  the error surface by ~50 sites (says 41/32; it is 91/56, and CLAUDE.md is right) — a fix plan
  scoped from the tracker inherits a 55%-too-small estimate (A73). `emit`/`upgrade` report a
  `pipeline.yml` defect as "this goal is not valid" and point at pydantic.dev — the A41 fix
  special-cased `ModuleContract` and left the `Pipeline` family (A74). Coded refusals don't route to
  `mendel explain` (A75). Plus two stale CLAUDE.md counts (A71/A72). The rest of the docs held —
  ARCHITECTURE.md type-by-type, the guides run, the four-door/seven-field/30-code claims all check.
- **A55 (critical) — a resolved value executes as Groovy.** `emit._ext_scope`'s non-templated
  branch appends `settings[].value` raw; a `${…}` becomes an `ext.<key> = { "…" }` closure that
  Nextflow evaluates per task. `key: prefix` is a legal, non-templated shape (MD0204 *refuses* a
  template on it), so no tampering is needed — only editing the value the file tells you to edit.
  Reproduced end to end: `id` ran on the host, outside any container, in the `docker` group, with
  the injection invisible in the task log. `pipeline.yml` is publishable; the victim just runs
  `mendel emit` or `mendel publish`. **This is a security issue on a public repo.**
- **A57, A58, A59 (critical) — the guards, defeated again, one layer up.** A57: the egress guard
  filters on `model_fields`, so a `@computed_field` or `@model_serializer` crosses a door unchecked.
  A58: `yaml.unsafe_load` is an RCE primitive *on the purity allowlist* — the static scan models
  stdlib capability, not third-party capability. A59: the runtime hook arms *after* `layers.load`,
  so the stage that parses stranger YAML is unwatched. **A58 and A59 compose** — `yaml.unsafe_load`
  inside `layers.load` reaches the network during the unwatched stage, defeating the union of both
  guards. This is A1/A17's result reproduced through routes their fixes do not cover.
- **A56 (important) — A54's fix made a lying resolver self-certifying.** A resolver returning
  `source=HUMAN` clears its own tier-4 flag *and* the fix writes the `human_override` that MD0220
  checks. Latent today (`FlagOnlyResolver` never says HUMAN); **live the moment Plan 2 wires a
  model to that port.** Invariant 6 — the difference from a chat window — is what it defeats.
- **A60, A62–A67 (important/minor) — the rest of the guard surface.** An `importlib` alias walks
  past the dynamic-importer check (A60, A18 again); an assignment alias or `model_construct` builds
  a `Pipeline` past the construction guard (A62); nine `Mark`s are bare `Annotated[str]` and carry
  paths and newlines through a door today (A64, no probe needed); `frozen` is one level deep so the
  publication evidence is mutable after review (A66).
- **A68, A69 (important) — the meta-findings, mine.** `test_pipeline_totality`'s headline guard
  compares field *names* in a flat set, so 60% of the fields it claims to check are checked against
  themselves — including three of the five the test was written to catch (A68). And A14's exit
  condition is measured per test *file* (46/47, reads as nearly done) when its condition is per
  *guard* (~34 of ~183) — the file-level residue is the wrong measure (A69).
