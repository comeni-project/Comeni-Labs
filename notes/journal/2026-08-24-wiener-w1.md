## The five findings worth carrying

Every one came from running the thing rather than from a test that was written to pass.

1. **`admit()` was dropping the fifteen `trace.enabled` fields** — and `run_event` is the
   record, so those runs have no resource history *ever*. Found at Checkpoint 2 by printing
   spans and asking why a number was missing.
2. **The record did not survive being read back.** `payload` is written by field name and
   `TaskTrace` validated by alias, so nine fields of fifteen came back `None` and
   `extra="ignore"` swallowed the evidence. It hid because three fields have no alias, so a
   span looked *sparse* rather than broken.
3. **The fold was doing nothing.** `prior` was read after the new row was inserted, so
   `fold(prior, event)` was a no-op every time and every ingest replayed the whole run. The
   state was still right, which is why nothing noticed — found by a gauge that went up and
   never came down.
4. **A run was two traces.** The SDK invents a random trace id for a parentless span, so the
   run span sat alone and five task spans pointed at a parent that did not exist. Only
   ClickHouse could see it; every unit test stubbed the emitter.
5. **`* task.attempt` was decoration.** The resource labels landed without an `errorStrategy`,
   so nothing ever retried and a task killed for memory would ask for the same amount again,
   forever. Found by a board panel that was empty.

## Two things Mendel gained

- **The emitted pipeline says what it asks for** — nf-core's `conf/base.config` label mappings,
  a convention quoted rather than a judgement invented, plus the retry that makes the
  `task.attempt` multiplier real. Without it §9.3's comparison had one side.
- **A cap is not a request.** What a machine *has* is a site fact, so `process.resourceLimits`
  is written by Wiener's launcher from the host, and the smoke profiles carry a modest cap of
  their own because a gate has no site config. `make verify` is what caught that — `req: 72 GB;
  avail: 31.3 GB`.

## What a fresh reader gets wrong

- **"The telemetry backend is part of the stack."** It is not. SigNoz deprecated its bundled
  Compose in v0.130.0, production is Kubernetes, and Wiener's whole integration is
  `WIENER_OTLP_ENDPOINT`. `ops/telemetry/README.md`.
- **"The boards were built in Grafana and exported."** They were authored as JSON with every
  panel's SQL verified against real data first, because this session could not click a UI.
- **"Checkpoint 3 and 5 were done in a browser."** The HTTP and WebSocket halves were driven
  and verified; **nobody has looked at these screens**. That is the gap 3E's lesson is about —
  twenty minutes of use found nine things that 76 green steps did not.
- **"`lost` is detected."** It is *produced* — the heartbeat cron asks `decide()` and writes the
  phase — but no run has ever gone quiet long enough to become one in practice.
- **"Auth exists."** §12.1 makes it a W1 requirement and phases 0–2 did not satisfy it. `lab_id`
  is server-chosen from settings and `submitted_by` is a string. **The first deployment anybody
  else can reach needs the check first.**
