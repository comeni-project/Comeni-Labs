## Six defects, every one found by running it

None of these is visible in a compose file, and none would have been caught by a test that did
not start a container.

1. **`sh -lc` is a login shell and resets `PATH`.** It re-reads `/etc/profile`, which drops
   `/app/.venv/bin`, so `alembic: not found` and the api exited on boot. Measured both ways:
   `sh -lc` gives `/usr/local/sbin:…` with no venv, `sh -c` keeps it. Cladewright uses `-lc` and
   gets away with it because its python is the system one.
2. **The containers ran as root, so git refused the mounted registry.** *"detected dubious
   ownership"* — the clone is owned by uid 1000 and the container was uid 0, so accepting a drift
   returned `MF0107` against a perfectly good checkout. The same change fixes the trap CLAUDE.md
   already records for Nextflow: every draft written into `./workspace` would have landed
   root-owned and undeletable.
3. **nginx resolves a literal upstream once and caches it forever.** Rebuilding the api gave it a
   new container IP and every request 502'd until nginx restarted — measured as
   `api direct 200 / via nginx 502 / nginx after a restart 200`. A `resolver` plus an upstream in
   a variable makes it re-resolve per request, which is what lets `make dev` rebuild the API
   underneath it.
4. **`ports: []` does not close a port.** Compose *merges* sequences across files, so the empty
   list adds nothing and the base's published port survives. Postgres was still answering on 5432
   with `ports: []` in the overlay. `!reset` is the mechanism.
5. **`npm run build` had never passed.** The gate every phase has run was `npx tsc --noEmit`,
   which uses looser settings than `tsc -b`'s project references — six type errors had
   accumulated, the oldest since slice 1. The root cause of four of them was one thing:
   `useUrlState`'s fallback drove inference, narrowing `T` to the empty string, so every
   `setState("undrafted")` was an error. `NoInfer` fixes it at the source rather than at each
   call.
6. **`README.md` and `LICENSE` are build inputs.** The root pyproject declares `readme =` and
   `license-files =`, so a dependency layer without them fails in `uv sync`.

## The test that was vacuous, again

`test_prod_publishes_only_the_web_port` asserted `ports == []` in the overlay — **and passed
while the ports were open**, because it read the literal it wanted to see rather than the
mechanism that produces the effect. It now asserts `!reset`, and was watched failing by reverting
one line.

That is the third vacuous test this protocol has caught in four phases, and they rhyme: each read
a value it had just written instead of a consequence.

## Two decisions worth carrying

**One compose file, one overlay.** Two independent files drift, and the drift shows up as *"it
works in dev"*. The overlay names only services the base defines — asserted — so a service cannot
be invented in one and missing from the other.

**`mendel-ai` is `mendel-forge[model]` now.** The served API cannot reach the model path —
invariant 3 confines runtime AI to three points and none is built — yet every import of the forge
pulled litellm: **152MB of a 285MB virtualenv**. Three import moves, all into the functions that
use them, and `filler.py` keeps its top-level imports because that module *is* the model path.
CLAUDE.md said the forge's default *is* the no-AI lane; this is what makes that structurally true
rather than documented. The fast suite dropped **60s → 41s** as a side effect, because every test
process had been importing a model client it never called.

## What you still cannot do

- **Deploy this.** No TLS, no auth — deferred since the interface spec — and no published image.
  `make prod` is the same stack with the unsafe parts removed, which is what makes it worth
  having locally: the path prod serves is a path you can test.
- **Accept a drift into the submodule.** By design: point `MENDEL_REGISTRY_ROOT` at a clone.
  `MF0107` says so in a sentence rather than crashing, which is the phase's other deliverable.
- **Trust the prod stack from a test.** It was brought up once, by hand. A test that runs
  `docker compose up` may not live in `make check`, so `tests/test_compose.py` reads the files
  instead — thirteen assertions, no container.
- **Click any of it.** Nine phases. That is now the operator's next step rather than a gap.
