# Plan 3A, phase 6 — sources and drafting

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement
> this plan task-by-task, sequentially, driving it yourself. Steps use checkbox (`- [ ]`) syntax,

> `subagent-driven-development`; subagents are for review and design only.

**Goal:** See what each source can read, see what has been done with each tool, and start a draft
— without a terminal.

**Architecture:** One `GET` answers *what can be read and what has been done with it* by joining
three things the API already has (discovery, the registry, the workspace); one `POST` wraps
`ops.draft` and supplies the paths from settings. The mounted forge transport is removed, because
it takes filesystem paths from the caller.

**Tech Stack:** FastAPI · React 19 · TypeScript 5.9 · react-router · TanStack Query · vitest.

**Spec:** [`notes/specs/2026-08-19-sources-and-drafting.md`](../specs/2026-08-19-sources-and-drafting.md)
— §3 holds the six decisions, §2 the inventory and the measurements.

**Design:** `docs/design/forge-review.md` **§9 lists Sources as undesigned**, so §3's rule — *a
page earns its place by being a different kind of work* — is the authority. Spec §3.5 and §3.6
are what it decided.

**Preceded by:** [`2026-08-19-plan-3a-phase-5.md`](2026-08-19-plan-3a-phase-5.md), complete.

## Task 1: Drafting over a draft is refused

**Files:**
- Modify: `packages/comeni-core/src/comeni_core/diagnostics.yml`,
  `packages/mendel-forge/src/mendel_forge/ops.py`, `packages/mendel-forge/tests/test_ops.py`

**Interfaces:**
- Produces: `MF0010`; `ops.draft` raises `ValueError` when `req.name` is already a draft.

**Why first:** it is a defect in `ops.draft` that has been true since forge phase 1, and every
later task calls that function. `Workspace.save` does `mkdir(exist_ok=True)` then `write_text`, so
drafting onto an existing name destroys every answer, proposal and decision on it — with no
refusal and no record. A CLI a person types deliberately survives that; a form does not.

- [x] **Step 1: Declare the diagnostic**

```yaml

MF0010:
  emitted_by: forge
  concern: drafting
  says: "a draft with that name already exists"
  fires_on: [forge draft]
  refuses: true
  fix: |
    Pick another name, or delete the draft you meant to replace. `forge show <name>` is what
    is in it.
  explanation: |
    `Workspace.save` writes a draft directory whether or not one is there, so drafting onto a
    name that is taken replaced every answer, proposal and decision on it and said nothing.
    A draft is the most expensive artifact in the system — it is a person's judgement, one
    field at a time, each with a reason — and the cheapest thing to protect it with is a name
    check. Overwriting is deliberately not offered as a flag: the recovery is to pick another
    name, and the caller always can.
```

```python
# packages/mendel-api/src/mendel_api/services/sources.py
"""What each registered source can read, and what has been done with each tool.

**One read, three joins.** Discovery says what exists, the registry says what has landed, and
the workspace says what is open. They are one question — *what can I start?* — so they are one
request; a screen firing three and joining them in the browser is the shape spec §4.1 rejects.

**No path crosses the boundary.** `settings` owns where the registry, the source and the
workspace live, which is why the forge's own transport is not what the browser calls: its
request models carry `source_root` and `workspace_root`, and a caller choosing those is a
second answer to a question `settings.py` answers once. Spec §3.1.
"""

from enum import StrEnum

from mendel_forge import ops
from mendel_resolver import layers
from pydantic import BaseModel

from mendel_api.settings import settings


class State(StrEnum):
    UNDRAFTED = "undrafted"
    """Neither drafted nor landed — this is what you can start."""
    DRAFTED = "drafted"
    """A draft in the workspace is about this tool. Answer it in the queue."""
    LANDED = "landed"
    """A contract with this module key is in the registry."""

    @property
    def rank(self) -> int:
        """What needs doing first, the same argument as the queue and the contracts list."""
        return {State.UNDRAFTED: 1, State.DRAFTED: 2, State.LANDED: 3}[self]


class ToolRow(BaseModel):
    ref: str
    """`nf-core:samtools/faidx` — a `ToolRef`, as the source spells it."""
    state: State
    contract_id: str | None = None
    """Set when landed, so the row can link to the module page."""
    draft: str | None = None
    """Set when drafted, so the row can link to the work that is open."""


class Catalogue(BaseModel):
    rows: list[ToolRow]
    counts: dict[str, int]
    """State -> how many, over everything discoverable rather than the filtered view."""
    sources: list[str]


def _module_key(ref: str) -> str:
    """`nf-core:samtools/faidx` -> `nf-core/samtools/faidx`, which is a contract id minus its
    version — invariant 11's module key, and the thing displacement is decided on."""
    return ref.replace(":", "/", 1)


def _drafts() -> dict[str, str]:
    """Module key -> draft name, read from each draft's `filled["id"]`.

    **Not from the draft's name.** A draft called `mydraft` for `samtools/faidx` is about that
    tool; the name is a label the person chose and `MF0008` only requires it be a directory.
    """
    found: dict[str, str] = {}
    for name in ops.list_(ops.ListRequest(workspace_root=settings.workspace_root)).names:
        shown = ops.show(
            ops.ShowRequest(
                name=name,
                registry_root=settings.registry_root,
                source_root=settings.source_root,
                workspace_root=settings.workspace_root,
            )
        )
        declared = shown.filled.get("id")
        if declared is not None:
            found.setdefault(str(declared.value).partition("@")[0], name)
    return found


def catalogue(*, state: State | None = None) -> Catalogue:
    refs = ops.discover(ops.DiscoverRequest(source_root=settings.source_root)).refs
    landed = {
        c.id.partition("@")[0]: c.id for c in layers.load(settings.registry_root).registry.all()
    }
    drafted = _drafts()

    rows = []
    for ref in refs:
        key = _module_key(ref)
        if key in landed:
            rows.append(ToolRow(ref=ref, state=State.LANDED, contract_id=landed[key]))
        elif key in drafted:
            rows.append(ToolRow(ref=ref, state=State.DRAFTED, draft=drafted[key]))
        else:
            rows.append(ToolRow(ref=ref, state=State.UNDRAFTED))

    counts = {member.value: 0 for member in State}
    for row in rows:
        counts[row.state.value] += 1

    if state is not None:
        rows = [r for r in rows if r.state is state]
    rows.sort(key=lambda r: (r.state.rank, r.ref))
    return Catalogue(rows=rows, counts=counts, sources=ops.sources_().names)


def draft(*, ref: str, name: str, version: str) -> ops.DraftResult:
    """Start a draft. **The three paths come from settings and never from the caller.**"""
    return ops.draft(
        ops.DraftRequest(
            ref=ref,
            name=name,
            version=version,
            registry_root=settings.registry_root,
            source_root=settings.source_root,
            workspace_root=settings.workspace_root,
        )
    )
```

**The mount goes, and the reason is the contract rather than the risk.** FastAPI does not merge a
mounted sub-app's schema into its parent, so a mount is a surface that exists and is **not in the
OpenAPI document** — invisible to the generated client and to an agent reading the same document.
Spec §3.2 states the rule that follows: *the served surface is exactly the OpenAPI document.*
`include_router` would satisfy the letter of that and is worse, because it would type and
advertise operations taking `source_root` and `workspace_root`.

**Two guards go in, and the second is the general form.** One says the app has no mounts; one says
no request body carries a path.

**And `mendel_forge/http/` is deleted, not left unmounted.** Measured: zero production consumers
once the mount goes, exercised only by its own two test files, and `fastapi` is an *optional
extra* in `mendel-forge` that nothing installs. Leaving it would also ship a contradiction — the
guide documents mounting it, with a worked example and no caveat, and this task removes the mount
for being unsafe. Spec §3.2 holds the argument and states what is lost.

# packages/mendel-api/tests/test_mount.py  — REPLACES the two mount assertions
"""The forge's transport is NOT mounted, and that is the assertion.

**It was, until phase 6.** `mendel_forge.http` ships an app that "binds nothing and has no
auth", and its docstring named `mendel-api` as the thing that would mount it and own who is
calling. Auth is deferred (interface spec §9), so what mounting it actually produced was an
unauthenticated app on the served origin whose request models take `registry_root`,
`source_root` and `workspace_root` — and whose `/drafts/land` runs `git commit` in whatever
path it is handed.

Three facts decided it: nothing in `frontend/src` called it, nothing *could* type it (a
mounted sub-app is absent from the parent's OpenAPI document, which is what the client is
generated from), and it accepts paths. `mendel_forge.http` still exists, still has its own
tests, and is still mountable by an operator who wants it — this app just does not do it.
"""


def test_the_served_surface_is_the_openapi_document():
    """No mounts — because a mount is by construction outside the document.

    FastAPI does not merge a mounted sub-app's schema into its parent, so anything mounted is a
    surface the generated client cannot see and an agent reading the schema cannot find. That is
    the rule; the forge transport is the instance that broke it.
    """
    from starlette.routing import Mount

    from mendel_api.main import create_app

    mounts = [(r.path, type(r).__name__) for r in create_app().routes if isinstance(r, Mount)]
    assert mounts == [], (
        f"{mounts} is served and not in the OpenAPI document. If a sub-app is wanted, it needs "
        "to be reachable through the schema — and the forge's own transport additionally takes "
        "filesystem paths from an unauthenticated body. Spec §3.2."
    )


def test_no_request_body_accepts_a_filesystem_path():
    """The general form of the same claim, over every body this app accepts.

    A field named for a root is how a path gets back in — not by someone re-mounting the
    forge, but by one convenience parameter on one route.

    **Asserted over the OpenAPI document rather than over `app.routes`.** Two reasons, and the
    first was found by running it: `include_router` nests the real routes, so iterating
    `app.routes` finds **zero** `APIRoute`s with a body and the test passes vacuously. The
    second is that the document is the honest surface — it is what `frontend/src/api/` is
    generated from and what an agent driving Mendel reads.
    """
    from mendel_api.main import create_app

    schema = create_app().openapi()
    defined = schema["components"]["schemas"]

    bodies = {}
    for path, methods in schema["paths"].items():
        for verb, op in methods.items():
            body = op.get("requestBody")
            if body is None:
                continue
            ref = body["content"]["application/json"]["schema"].get("$ref", "")
            bodies[f"{verb.upper()} {path}"] = ref.rsplit("/", 1)[-1]

    assert len(bodies) >= 6, f"the scan found {len(bodies)} bodies — it is not scanning"
    offenders = [
        f"{where} {model}.{field}"
        for where, model in bodies.items()
        for field in defined.get(model, {}).get("properties", {})
        if field.endswith("_root") or field.endswith("_path")
    ]
    assert offenders == [], f"a request body takes a filesystem path: {offenders}"
```

from fastapi import APIRouter, Query
from mendel_forge.ops import DraftResult
from pydantic import BaseModel, ConfigDict

from mendel_api.refusals import REFUSES
from mendel_api.services import sources as service
from mendel_api.services.sources import Catalogue, State

router = APIRouter(prefix="/sources", tags=["sources"])


class DraftBody(BaseModel):
    model_config = ConfigDict(extra="forbid")
    """**Forbid, not ignore.** A request naming `workspace_root` must be a refusal rather than
    a silently discarded field — that is the difference between a boundary and a habit."""

    ref: str
    name: str
    version: str
    """Asked for, never derived. Two of the thirteen vendored tools have a container with no
    version in it at all, and one shipped contract disagrees with the tag it does have —
    spec §3.3."""


@router.get("", operation_id="listSources", summary="What can be read, and what has been done")
def catalogue(
    state: Annotated[State | None, Query(description="Only this state.")] = None,
) -> Catalogue:
    return service.catalogue(state=state)


@router.post(
    "/draft", operation_id="draftTool", summary="Start a draft from a source", responses=REFUSES
)
def draft(body: DraftBody) -> DraftResult:
    return service.draft(ref=body.ref, name=body.name, version=body.version)
```

**The audit found four things, and all four are in the plan above rather than left to discovery.**

1. **The mounted forge transport cannot be called from a browser at all.** Its request models
   carry `source_root` and `workspace_root`; a caller supplying those is the second answer to a
   question `settings.py` exists to answer once. This is why phase 6 adds routes, and it is also
   why `main.py`'s "never re-exposed route by route" docstring has been false since phase 2.
2. **`Workspace.save` overwrites a draft silently.** `mkdir(exist_ok=True)` then `write_text`,
   no check. Task 1 is that defect, and it has been true since forge phase 1.
3. **The version is not derivable, measured rather than assumed.** `star/align` and
   `hisat2/align` have containers with **no version tag at all**, and `samtools/index@1.21.0`
   ships against a `1.24` container. A prefilled field would be authoritative and wrong.
4. **`test_mount.py` asserts the mount exists**, in two tests, one of which explains why a mount
   is the right shape. Removing it means inverting a guard rather than deleting one, and the
   replacement has to carry the argument — which is why Task 3 writes the new docstring out in
   full rather than saying "update the test".
5. **The boundary test's first draft could not have failed.** It iterated `app.routes` looking
   for `APIRoute.body_field`, and **every one is `None`** — `include_router` nests the real
   routes, and `body_field` is not where the model lives in this FastAPI version either.
   Measured: zero bodies found that way, five found through `app.openapi()`. The test asserts
   over the document instead, and asserts the scan reached something before asserting what it
   did not find.

**Two things were verified by running them rather than assumed:** `extra="forbid"` on a body does
answer **422** for an unexpected field (so §3.1's boundary is enforced by the model rather than by
a check), and `create_app().routes` **does** surface the `Mount` — so the mount half of
`test_mount.py` works as written even though the route half did not.

**Known weak points, stated rather than hidden:**

- **The module is deleted rather than kept unmounted**, on the operator's instruction not to leave
  hidden dead code — and the measurement backs it: zero production consumers, an optional extra
  nothing installs, and a guide section documenting the mount this task removes. **What is lost is
  the CLI-to-HTTP payload parity guard**, and it does not transfer to `mendel-api`, whose payloads
  are deliberately different shapes. Spec §3.2 says so rather than letting it go quietly.
- **A dozen docstrings mention `mendel_forge.http` in prose** and are deliberately left alone —
  they describe a convention (a coded refusal is a 422) that outlives the module. If that reads
  wrong during execution, fix the two that describe *code* and leave the rest; a sweep across
  every file is noise with no reader.
- **`_drafts()` calls `ops.show` once per draft**, which re-reads the registry each time — the
  same cost `queue.read()` already pays and the journal already recorded. Fine at two drafts;
  it is the second place that would need the same fix.
- **`test_no_route_accepts_a_filesystem_path` inspects `route.body_field.type_`**, which is
  FastAPI internals. If that attribute moves, the test breaks loudly rather than silently
  passing — acceptable, and worth knowing it is not a public API.
- **The exit criterion drafts `samtools/faidx` at version `1.24`**, read off its container. That
  is a guess by exactly the reasoning §3.3 says not to trust, and it is fine for a demo — but the
  journal should not present it as the right answer.
- **Nobody has clicked any of it**, which will be seven phases running.
