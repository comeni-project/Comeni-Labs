# Tutorials

Start with [Your first pipeline](first-pipeline.md) to inspect an
RNA-seq draft, review its decisions, examine the saved artifact and follow the local
run workflow. The [RNA-seq example](rnaseq-example.md) supplies the
scientific context and expected pipeline shape.

Before starting, [install and open the app](../how-to/install.md).
The walkthrough uses the manual builder, which can be opened without configuring a model.

Once you have worked through the example, use the [how-to guides](../how-to/index.md)
for individual tasks and [explanation](../explanation/index.md) for the reasons behind
the choices you saw.
