## What changed that a returning reader will trip over

Three of these move things that were true yesterday.

- **`resolve()` takes `measurements` as a required fourth positional argument.** Twelve call
  sites and a README were updated. It is required rather than optional on purpose: an optional
  guard is the guard the next verb forgets, which *is* A2.
- **`route()` takes a resolver, and `RoutePlan.ambiguities` is now `RoutePlan.decisions`** —
  resolved records rather than open questions, because the resolver is asked where the choice
  is made and can still change it.
- **A registry layer is named by `registry.yml`, not by its directory.** Lockfiles and bundles
  now say `comeni-registry-examples` where they said `registry`. That is the only golden change
  in the whole plan so far; no `.nf` moved.
- **A registry layer may not contain a symlink.** Both the loader and the digest refuse one.

## The finding behind the findings

Nine of the thirteen fixes move a check out of a caller and into a type. **A guard in a caller
is a guard the next caller forgets.** A2 is the pure case: invariant 15 was enforced in
`mendel build`'s own re-route, so `mendel upgrade` — the one verb that reads a file a stranger
wrote — had no check at all.

The second lesson is newer and sharper, and it is the reason Task 12 must add a fourteenth
finding rather than only tick off thirteen:

> **A guard that has never been watched failing may be inert, not merely weak.**

Three times today a test passed against code that was deliberately broken:

1. `test_two_layers_sharing_a_basename_do_not_collapse` asserted that *some* drift line
   mentioned the layer. Both wrong implementations of `drift_against` report a line there. The
   test had been unable to fail since Plan 1.7. Found by reverting the code, not by reading it.
2. Task 6's first fixture used one resolver for both ambiguity sites — but `_choose` defaulted
   to `ordered[0]` and `_source_for` to `equally_good[-1]`, so a resolver disagreeing with one
   agreed with the other, and the edge tests passed against unfixed code.
3. That same edge test asserted over an empty loop: two aligner *contracts* only route one, so
   no source ambiguity ever arose.

**Round two should revert code and watch, not read.** Reading found A1–A13; reverting found
three inert guards in a single day.
