## Found while executing, not by the audit

**Adding a field to the artifact schema invalidates every archived `pipeline.yml`.** Task 3's
step 6 — "verify against a pipeline this code did not write" — upgraded an artifact built before
1.13 existed:

```
recorded from_digest: sha256:e0fe1d12…
recomputed          : sha256:b96a7f4b…
→ MD0213: pipeline.yml has changed since the Nextflow was generated from it
```

The emitted `main.nf` and `nextflow.config` hashed **exactly** to their recorded digests. The
pipeline had not changed; the reader had. `from_digest` hashes the model dump, so any new field
with a default moves it.

Two things are wrong and only one is the digest: **the diagnostic lies** — a lab reading that
goes looking for an edit nobody made — and **there is no migration story**, while Plan 1.14 adds
six more fields on top of a `version:` bump. It is now **Task 0 of Plan 1.14**, with a
`schema_version` beside `from_digest` so `MD0213` can tell "you edited this" from "the schema
moved; re-emit to restamp, your Nextflow is unaffected".

By the operator's call, 1.13 finished first rather than stopping to fix it, and it is fixed
before anything else in 1.14.

## Plan corrections, recorded because the rule earns itself every time

1. `resolve()` returns a `PipelineIR`, not a `Pipeline` — the fixture needed `Pipeline.of(...)`.
2. There is no `tests/conftest.py`; `test_join.py` carries its own fixture.
3. `measurements.states_of(param)` does not exist and could not: a `MeasurementRegistry` holds
   measurements, not parameter domains. A `Param` has **no declared domain at all** — Plan 2
   correction 6 — which is why `MD0300` reasons about the shape of the string instead.
4. A substring test for A118 would refuse `paired-end`, since `paired` is a declared
   measurement. The check requires a measurement adjacent to an operator **and a number**.
5. `replay.py`'s key is used in three places, not one.
6. Audit-finding tests belong in `test_audit_regressions.py` by its own `test_a<N>_` convention,
   not in the files the plan named.
