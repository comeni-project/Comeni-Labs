# What is not built yet

Comeni Labs is **Alpha, pre-MVP**. The user-facing books are written to the product as it will be, and every place reality has not caught up carries a marker. This page is generated from those markers, so it cannot go stale.

Nothing is marked as future-only. The pages describe current alpha behavior, including surfaces that may still change.
