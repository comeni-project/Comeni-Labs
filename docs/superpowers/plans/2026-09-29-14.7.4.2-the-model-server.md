**Goal:** The Compose stack's Ollama keeps the model loaded, serves one slot so a prompt's prefix
can be reused, and runs a current release — and we know, in numbers, whether an identical prompt
is still re-read.

**Architecture:** Deployment configuration only. `docker-compose.yml` gains
`OLLAMA_KEEP_ALIVE` and `OLLAMA_NUM_PARALLEL` with defaults an operator can override, and the
image default moves to a current pinned release. The app changes nothing and assumes nothing: a
Kubernetes deployment sets its own. A small probe (`tools/probe_prompt_cache.py`) measures prompt
evaluation from Ollama's own timings; it is run here and again after part 3's split.

**Tech stack:** Docker Compose, Ollama, Python (the probe, stdlib only).

**Spec:** [`docs/superpowers/specs/2026-09-29-the-consultants-words-design.md`](../specs/2026-09-29-the-consultants-words-design.md) §6 *The model server (Docker)*.
**Issues:** #184 (keep_alive), #185 (prefix reuse) under 14.7.4 (#180).

## Global constraints

- **The app assumes nothing about the model server** (operator: *this will be done in the actual
  deployment by Kubernetes; Docker-only is fine; document it and leave it open to multiple
  behaviours*). No `keep_alive` in any request; no code path that needs one slot.
- **Pin an exact image version**, never `latest`: a model server that changes under a walk makes
  the walk's numbers unrepeatable.
- **The operator's `.env` is theirs:** changing `OLLAMA_IMAGE` there is named in the step and
  reported, not done silently.
- **Run each check in its own call; commit in a separate call.**

- [x] **Step 1: Write the probe** (stdlib only; runs inside `mendel-api`, which has the prompts):

```python
"""Measure whether Ollama re-reads a prompt's fixed part — #185.

Sends the builder's goal prompt to /api/chat three ways and prints Ollama's own timings:
the same prompt twice (a repeat should read almost nothing), and a second request sharing the
fixed part (prefix reuse across different questions). Run inside the api container:
    docker cp tools/probe_prompt_cache.py mendel-api:/tmp/ && \\
    docker exec mendel-api python /tmp/probe_prompt_cache.py [model]
"""

import json
import sys
import urllib.request

from comeni_ai.client import _prompt
from mendel_api.authoring import prompts
from mendel_api.authoring.types import WantUnderstanding
from mendel_api.services import authoring_ai as ai
from mendel_api.services import registry

MODEL = sys.argv[1] if len(sys.argv) > 1 else "gemma3:12b"
BASE = "http://ollama:11434/api/chat"


def prompt_for(request: str) -> str:
    text = prompts.template(prompts.GOAL).render(
        {"vocabulary": ai._vocabulary_text(registry.stack()), "conversation": "",
         "request": request}
    ).text
    return _prompt(text, WantUnderstanding, [])


def chat(prompt: str) -> str:
    body = json.dumps({"model": MODEL, "stream": False, "options": {"temperature": 0},
                       "messages": [{"role": "user", "content": prompt}]}).encode()
    request = urllib.request.Request(BASE, data=body, headers={"content-type": "application/json"})
    r = json.load(urllib.request.urlopen(request, timeout=600))
    s = lambda k: round(r.get(k, 0) / 1e9, 1)  # noqa: E731
    return (f"load={s('load_duration')}s prompt={r.get('prompt_eval_count')}tok/"
            f"{s('prompt_eval_duration')}s gen={r.get('eval_count')}tok/{s('eval_duration')}s")


a = prompt_for("paired-end RNA-seq to gene counts, 150 bp reads, I have the human genome")
b = prompt_for("single-cell RNA-seq to a counts matrix")
print("warm-up      ", chat(a))
print("identical    ", chat(a))
print("shared prefix", chat(b))
```
