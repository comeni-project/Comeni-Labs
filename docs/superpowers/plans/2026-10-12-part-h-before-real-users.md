# Before real users (Part H) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A laboratory can keep sessions and runs across upgrades without a row being misread,
delete a draft or a run, see and change how long everything is kept, and lose no queued run to a
Redis crash.

**Architecture:** Each service gets a shape registry (`shape_versions.py` with the numbers,
`shapes.py` with the models), a `shape_version` stamp on every table holding JSON, a load
listener that refuses a stale stamp, and one migration converting `JSON` to `JSONB`. Wiener writes
`params.json` at submit and the job carries only the run id. Retention is two delete routes, a
daily sweep per service, and two *Data retention* sections on the Settings page — Mendel's
stored as installation settings, Wiener's in Wiener's own table, written through a new Wiener
`PUT`.

**Tech Stack:** Python 3.12, SQLAlchemy 2, Alembic, Postgres (JSONB), arq cron, FastAPI, Pydantic
2, React 19 + TanStack Query + Vitest.

**Spec:** `docs/superpowers/specs/2026-10-12-part-h-before-real-users-design.md`

## Global Constraints

- Work on `stage-four-the-consultant-build`; never `main`; push nothing.
- Every guard is watched failing against the specific defect, and gets a row in
  `tests/fixtures/guard-ledger.md` (test name, what was reverted, what it said).
- Diagnostics are declared in `packages/comeni-core/src/comeni_core/diagnostics.yml` and raised
  through `coded()`; after adding any, run `uv run python tools/generate_diagnostics_doc.py`.
- New codes: `MI0400`–`MI0499` (*the API: what is stored — shapes and retention*), `MW0100`–
  `MW0199` (*wiener: what is stored*). Add both band lines to the header comment of
  `diagnostics.yml`.
- Retention defaults, verbatim from the spec: working files of a succeeded run `0` days (*when
  the run ends*); of a failed, cancelled or lost run `7`; model replies `30`; drafts, runs and
  results *kept* (`null`).
- Retention choices (one list for every category): `keep` → *Kept until deleted*, `0` → *When the
  run ends* (working files only), `1`, `7`, `30`, `90`, `365` → *After N days*.
- No table holds run parameters (§7.1 of the retired Wiener design; invariant 15).
- Every Wiener query lives in `wiener_api/repository.py` and takes a `lab_id`.
- `frontend/src/api/` is generated by `make client`, never hand-edited; the Wiener client types
  are in `frontend/src/wiener/api/` and are regenerated by the same command.
- Python tests run from the repository root with the throwaway database:
  `make test-db` once, then `$SP/part-h-run uv run pytest …` where `$SP/part-h-run` exports
  `MENDEL_DATABASE_URL` and `WIENER_TEST_DATABASE_URL` for `127.0.0.1:5442` (copy
  `part-g-run` from the scratchpad, or write it from `Makefile`'s `test:` target).
- Frontend: `cd frontend && npx vitest run <file> && npx tsc -b`.
- `make check` before every task's commit; `make verify` once in Task 9.

## Review Focus

1. **JSONB reorders keys.** An offer's `options` and a proposal's `preview_views` are drawn in
   the order they were written. Expected: every list a person sees keeps its order after a
   reload. Pinned by Task 1's key-order round trip over a walked session.
2. **A draft forked from the one deleted.** Expected: the fork still opens, its own history
   intact, and its fork columns cleared together (`complete_fork` CHECK). Pinned in Task 4.
3. **Deleting a run whose artifact another run still uses.** Expected: the other run still
   launches and shows its pipeline. Pinned in Task 5.
4. **The sweep at the boundary and on an empty installation.** Expected: nothing a day younger
   than its limit is touched; a pass with nothing to do still writes its zero counts. Pinned in
   Task 7.
5. **Wiener down while Settings is open.** Expected: Mendel's *Data retention* is still editable
   and Wiener's section says it could not be read, as *Running* does today. Pinned in Task 8.

```python
def _json_columns() -> set[tuple[str, str]]:
    found = {(t.name, c.name) for t in Base.metadata.tables.values() for c in t.columns

    """A changed model with an unchanged version fails here: bump the version, write an
    upgrader and its migration (spec §3.3). `COMENI_WRITE_GOLDEN=1` writes a missing golden."""
    from mendel_api.shape_versions import VERSIONS
    from mendel_api.shapes import SHAPES

    assert SHAPES
    for shape in SHAPES:
```

```python
def _order(value):
    """The nested key order of a JSON value: what JSONB may change and a person may see."""
    if isinstance(value, dict):
        return [(k, _order(v)) for k, v in value.items()]
    if isinstance(value, list):
        return [_order(v) for v in value]
    return None


@needs_db
def test_a_walked_offer_keeps_its_order_through_a_reload(g_case):
    """`options` is drawn in the order it was written (keep first). JSONB orders keys by
    length, then bytes; a column whose order a person sees must not depend on that."""
    from mendel_api.authoring import envelopes
    from mendel_api.models import PipelineAuthoringProposal

    with session_scope() as db:
        row = db.get(PipelineAuthoringProposal, g_case.proposal_id)
        stored = row.payload
        views = row.preview_views
    written = envelopes.parse(stored, kind=stored["offer"]).model_dump(mode="json")
    assert list(stored["options"]) == list(written["options"]), "offer options reordered"
    assert list(stored["options"])[0] == "keep"
    assert _order(stored) == _order(written)
    if views:
        assert list(views) == stored["preview_options"]
```

```python
"""Which shape each table's JSON is in (spec §3). **Numbers only, importing nothing**, so
`models.py` can stamp its tables without importing the models that type their columns.

Bump a table's number when any of its JSON columns changes shape, in the same commit as the
upgrader in `shapes_upgrade.py` and the migration that runs it.
"""

from sqlalchemy import Integer, text
from sqlalchemy.orm import Mapped, mapped_column

VERSIONS: dict[str, int] = {
    "ai_invocation": 1,
    "forge_catalogue_item": 1,
    "forge_message": 1,
    "forge_revision": 1,
    "forge_source_snapshot": 1,
    "installation_setting": 1,
    "pipeline_authoring_proposal": 1,
    "pipeline_authoring_session": 1,
    "pipeline_authoring_turn": 1,
    "pipeline_decision_migration": 1,
    "pipeline_draft": 1,
    "pipeline_input_revision": 1,
    "pipeline_observation": 1,
    "pipeline_parameter_revision": 1,
    "pipeline_phrasing": 1,
    "pipeline_producer_revision": 1,
    "pipeline_want_revision": 1,
}


def stamp(table: str) -> Mapped[int]:
    """The `shape_version` column: written by the ORM and by a raw `INSERT` alike, since the
    server default carries the number (`decisions_v1` and `forge_catalogue` insert in SQL)."""
    return mapped_column(Integer, nullable=False, default=VERSIONS[table],
                         server_default=text(str(VERSIONS[table])))
```

- [x] **Step 4: Write `shapes.py`**

```python
"""What each JSON column holds, and the refusal of a row in an older shape (spec §3).

`SHAPES` is what the golden test pins: a column's JSON Schema at its table's version. The load
check reads only `VERSIONS`. **A row is refused, never misread**: a stale stamp means a
migration did not run over it, and guessing its shape is the failure issue 276 named.
"""

from dataclasses import dataclass
from typing import Any

from comeni_core.diagnostics import coded
from pydantic import JsonValue
from sqlalchemy import JSON, event
from sqlalchemy.dialects.postgresql import JSONB

from mendel_api.shape_versions import VERSIONS

Json = JSON().with_variant(JSONB(), "postgresql")
"""Every JSON column's type: `JSONB` in Postgres, plain JSON where a test runs on SQLite."""


@dataclass(frozen=True)
class Shape:
    table: str
    column: str
    model: Any  # a type a `TypeAdapter` accepts


class StaleShape(RuntimeError):
    """A row whose `shape_version` is not its table's. Raised on load."""


def _shapes() -> tuple[Shape, ...]:
    from comeni_core.goal.profile import Evidence
    from comeni_core.plan.draft import DraftGraph
    from comeni_core.spell.marks import ParamValue
    from mendel_authoring.payloads import Extraction
    from mendel_forge.ai.schemas import Citation

    from mendel_api.authoring.canvas import AlternativePreview
    from mendel_api.authoring.types import AskedGap, Block
    from mendel_api.migration_data.decisions_v1 import Snapshot
    from mendel_api.services.forge_catalogue import CatalogueItem

    loose = dict[str, JsonValue]
    return (
        Shape("ai_invocation", "input_digests", dict[str, str]),
        Shape("forge_catalogue_item", "metadata", CatalogueItem),
        Shape("forge_message", "citations", list[Citation]),
        Shape("forge_revision", "manifest", loose),
        Shape("forge_revision", "validation", loose),
        Shape("forge_revision", "prompt_versions", dict[str, str]),
        Shape("forge_source_snapshot", "counts", loose),
        Shape("forge_source_snapshot", "filters", list[loose]),
        Shape("forge_source_snapshot", "warnings", list[loose]),
        Shape("installation_setting", "value", JsonValue),
        Shape("pipeline_authoring_proposal", "payload", loose),
        Shape("pipeline_authoring_proposal", "preview_views", dict[str, AlternativePreview] | None),
        Shape("pipeline_authoring_session", "extraction", Extraction | None),
        Shape("pipeline_authoring_session", "blueprint", loose),
        Shape("pipeline_authoring_turn", "blocks", list[Block]),
        Shape("pipeline_decision_migration", "snapshot", Snapshot),
        Shape("pipeline_draft", "graph", DraftGraph),
        Shape("pipeline_draft", "provenance", loose),
        Shape("pipeline_input_revision", "states", list[str]),
        Shape("pipeline_observation", "value", ParamValue | list[ParamValue] | None),
        Shape("pipeline_observation", "pieces", list[str]),
        Shape("pipeline_observation", "evidence", Evidence | None),
        Shape("pipeline_parameter_revision", "value", JsonValue),
        Shape("pipeline_phrasing", "asked", AskedGap | None),
        Shape("pipeline_producer_revision", "states", list[str]),
        Shape("pipeline_want_revision", "states", list[str]),
    )


class _Lazy:
    """`SHAPES` imports the models lazily, so importing this module from `db.py` cycles nothing."""

    def __iter__(self):
        return iter(_shapes())

    def __bool__(self):
        return True


SHAPES = _Lazy()


def _check(target, _context) -> None:
    table = getattr(target, "__tablename__", None)
    if table not in VERSIONS:
        return
    found = getattr(target, "shape_version", None)
    if found != VERSIONS[table]:
        raise StaleShape(coded(
            "MI0400",
            f"{table} row {getattr(target, 'id', getattr(target, 'key', '?'))} is in shape "
            f"{found}, and this server reads shape {VERSIONS[table]}: run the migrations",
        ))


def install(base) -> None:
    """Refuse every loaded row in an older shape. Called once, from `db.py`."""
    event.listen(base, "load", _check, propagate=True)
    event.listen(base, "refresh", lambda target, context, attrs: _check(target, context),
                 propagate=True)
```

```python
"""Every JSON column becomes JSONB, and every table holding JSON records its shape (Part H)."""

import sqlalchemy as sa
from alembic import op

revision = "c4e8a2f6d913"
down_revision = "b9d3e7f5c164"
branch_labels = None
depends_on = None


def upgrade():
    bind = op.get_bind()
    columns = bind.execute(sa.text(
        "SELECT table_name, column_name FROM information_schema.columns "
        "WHERE table_schema = current_schema() AND data_type = 'json' "
        "AND table_name <> 'alembic_version' ORDER BY table_name, column_name")).all()
    tables = sorted({t for t, _ in columns})
    for table, column in columns:
        op.execute(f'ALTER TABLE {table} ALTER COLUMN "{column}" TYPE JSONB '
                   f'USING "{column}"::jsonb')
    for table in tables:
        op.add_column(table, sa.Column("shape_version", sa.Integer(), nullable=False,
                                       server_default="1"))


def downgrade():
    raise RuntimeError("Restore a verified backup rather than narrow JSONB back to JSON.")
```

```python
Children first, in one transaction: the decision rows' subject↔revision cycle is deferred, every

from typing import NamedTuple

import sqlalchemy as sa
from comeni_core.diagnostics import coded

    "pipeline_input_revision", "pipeline_want_revision", "pipeline_fact_revision",
    "pipeline_producer_revision", "pipeline_parameter_revision", "pipeline_review_revision",

    rows: int
    replies_cleared: int


def clear_replies(db, where, reason: str) -> int:
    result = db.execute(sa.update(AiInvocation).where(where, AiInvocation.response.is_not(None))
                        .values(response=None, response_cleared=reason,
                                response_cleared_at=datetime.now(UTC)))

def delete_draft(draft_id: str) -> Deleted:
    with session_scope() as db:
        draft = db.get(PipelineDraft, draft_id, with_for_update=True)
        if draft is None:
            raise KeyError(draft_id)
        live = db.scalar(sa.select(sa.func.count()).select_from(GateRun).where(
            GateRun.draft_id == draft_id,
            GateRun.state.in_([GateState.QUEUED, GateState.RUNNING])))
        if live:
            raise ValueError(coded("MI0401", "a gate is running on this draft; wait for it or "
                                             "let it finish before deleting"))
        sessions = list(db.scalars(sa.select(PipelineAuthoringSession.id)
                                   .where(PipelineAuthoringSession.draft_id == draft_id)))
        cleared = clear_replies(db, AiInvocation.session_id.in_(sessions), "deleted") if sessions else 0
        rows = 0
        for table in _BY_DRAFT:
            rows += db.execute(sa.text(f"DELETE FROM {table} WHERE draft_id = :d"),
                               {"d": draft_id}).rowcount
        if sessions:
            for table in ("pipeline_authoring_proposal", "pipeline_authoring_turn"):
                rows += db.execute(sa.text(f"DELETE FROM {table} WHERE session_id = ANY(:s)"),
                                   {"s": sessions}).rowcount
            rows += db.execute(sa.text("DELETE FROM pipeline_authoring_session "
                                       "WHERE draft_id = :d"), {"d": draft_id}).rowcount
        rows += db.execute(sa.delete(GateRun).where(GateRun.draft_id == draft_id)).rowcount
        db.execute(sa.update(PipelineDraft).where(PipelineDraft.forked_from == draft_id).values(
            forked_from=None, fork_key=None, fork_sequence=None, fork_at=None))
        db.delete(draft)
        rows += 1
    shutil.rmtree(settings.draft_root / draft_id, ignore_errors=True)
    return Deleted(rows, cleared)
```

```python
"""Deleting a run a person asks to delete (spec §5.1). Only a finished one; permanent."""

import shutil

from wiener_core.state import RunPhase

from wiener_api import db, repository
from wiener_api.services import launcher, stream
from wiener_api.settings import settings

FINISHED = {RunPhase.SUCCEEDED, RunPhase.FAILED, RunPhase.CANCELLED, RunPhase.LOST}


class Refused(Exception):
    pass


def delete_run(run_id: str) -> None:
    with db.session_scope() as session:
        run = repository.run(session, settings.lab_id, run_id, lock=True)
        if run is None:
            raise LookupError(run_id)
        if RunPhase(run.phase) not in FINISHED:
            raise Refused(f"this run is {run.phase}: cancel it first, then delete it")
        artifact_id = run.artifact_id
        repository.delete_run(session, settings.lab_id, run_id)
        orphaned = not repository.artifact_in_use(session, settings.lab_id, artifact_id)
        if orphaned:
            repository.delete_artifact(session, settings.lab_id, artifact_id)
    shutil.rmtree(launcher.work_dir(run_id), ignore_errors=True)
    stream.drop(run_id)
    if orphaned:
        shutil.rmtree(settings.artifact_root / artifact_id, ignore_errors=True)
```

```python
"""The daily sweep (spec §5.2): what is past its limit goes, and every pass is recorded."""

from datetime import datetime, timedelta

import sqlalchemy as sa
from comeni_core.settings import catalogue
from comeni_core.settings.retention import days

from mendel_api.services.installation import installation


def _limit(setting) -> int | None:
    return days(str(installation().get(setting)))


def sweep(now: datetime) -> dict[str, int]:
    removed = {"model_replies": 0, "drafts": 0}
    if (limit := _limit(catalogue.MODEL_REPLIES)) is not None:
        with session_scope() as db:
            removed["model_replies"] = deletion.clear_replies(
                db, sa.and_(AiInvocation.agent == "builder",
                            AiInvocation.started_at < now - timedelta(days=limit)),
                "retention")
    if (limit := _limit(catalogue.DRAFTS)) is not None:
        with session_scope() as db:
            old = list(db.scalars(sa.select(PipelineDraft.id).where(
                PipelineDraft.updated_at < now - timedelta(days=limit))))
        for draft_id in old:
            try:
                deletion.delete_draft(draft_id)
                removed["drafts"] += 1
            except ValueError:
                continue  # a gate is running: next pass
    with session_scope() as db:
        for category, count in removed.items():
            db.add(RetentionSweep(ran_at=now, category=category, removed=count))
    return removed


async def retention_sweep(ctx: dict) -> dict[str, int]:
    from datetime import UTC
    return sweep(datetime.now(UTC))
```
