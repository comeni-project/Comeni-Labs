# 14.7.4 part 7 — When nothing fits: ask, never force — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task by task, in one hand. Tick each `- [ ]` as it completes; deviations go in the
> execution record.

**Goal:** A request nothing here can produce ends in a question to the person, never in a forced
family or a `failed` session. A request that fits behaves exactly as it does today.

**Architecture:** Two layers.
- **The verdict.** The family call answers `fits` (`yes` / `no` / `unsure`) *before* any list
  (`builder.family.v2`), and the engine asks unless the verdict is `yes` with a family listed.
- **The safety net.** When nothing can make a model-chosen want, `offer_next_gap` asks instead of
  failing. It records `MI0209`, clears the want, and moves the session *gathering → understanding*
  on a new event, `WANT_UNREACHABLE`. The protocol object gains that edge and loses
  `list_needs → failed`, and the diagram is regenerated.

**Tech stack:** Python 3.12, Pydantic 2, pytest, the real stack for the walk (gemma3:12b through
Ollama).

**Spec:** [`docs/superpowers/specs/2026-09-30-when-nothing-fits-design.md`](../specs/2026-09-30-when-nothing-fits-design.md).
**Issue:** #202 (decided 2026-09-30) under 14.7.4 (#180).

## Global constraints

- **Nothing is guessed silently.** Any verdict other than `yes` with a family listed asks. Any
  families listed beside a `no` are ignored.
- **Verdict before list:** `fits` is the first property of `FamilyChoice`'s JSON schema.
- **A retired prompt stays on disk, unedited**: `builder.family.v1` moves to `prompts.RETIRED`.
- **The engine's dead-end question names no type id**, and `MI0209` is still recorded, as a notice
  on the same engine turn.
- **Only a model-chosen want reaches the new path.** A goal edited on the card is untouched, and
  so is `resolve → failed` (*can't build it*).
- **The protocol is edited in `protocol.py`**, never in `state.TRANSITIONS`. The diagram is
  regenerated with `uv run python tools/generate_protocol_doc.py`.
- **Tests use fake transports only**, never a live model. DB tests need
  `MENDEL_DATABASE_URL=postgresql+psycopg://mendel:mendel@127.0.0.1:5442/mendel` (the throwaway
  `walk-testdb`).

## Review focus

1. **After a dead end, the person's next reply is read from the top.** The next turn runs the
   family call again, not the follow-up call. This is pinned in Task 7.2, step 1
   (`test_after_a_dead_end_the_next_reply_is_read_from_the_top`).
2. **A `yes` with an empty list** would reach the goal call with no families, and v7 would be
   shown nothing. It must ask instead. Pinned in Task 7.1
   (`test_a_yes_with_nothing_listed_asks`).
3. **The engine's question must not carry the model's type id.** Pinned in Task 7.2
   (`assert "annotation.gtf" not in asks`).
4. **A gap answered after the want is set** also runs `offer_next_gap`. The want is unchanged
   there, so it cannot newly become unreachable; the existing gathering tests cover that path and
   must stay green.
5. **A stale `goal` after the dead end:** the card's `stated` and `suggested` must not leak into
   the next reading. Clearing the whole goal column covers it. Pinned in Task 7.2
   (`goal is None`).

  ```python
  """#202 walk: each sentence through the real stack; the no-fit ones must end in a question."""
  import json, sys, time, urllib.request

  B = "http://localhost/api/pipeline/authoring"
  NO_FIT = ["variant calls from my exomes", "a phylogenetic tree from my 16S amplicons",
            "peaks from my ChIP-seq"]
  FIT = ["gene counts from my RNA-seq reads",
         "single-end RNA-seq, I want gene counts",
         "I have paired-end human RNA-seq reads, 150 bp, and want gene counts"]

  def call(path, body=None):
      data = None if body is None else json.dumps(body).encode()
      req = urllib.request.Request(B + path, data=data, method="POST" if body else "GET",
                                   headers={"content-type": "application/json"})
      return json.load(urllib.request.urlopen(req))

  def settle(sid):
      for _ in range(120):
          v = call(f"/{sid}")
          if not any(t.get("state") == "pending" for t in v["turns"]):
              return v
          time.sleep(1)
      raise TimeoutError(sid)

  for text in NO_FIT + FIT:
      sid = call("", {"prompt": text, "mode": "build"})["session"]["id"]
      v = settle(sid)
      calls = call(f"/{sid}/calls")
      last = v["turns"][-1]["blocks"]
      print(f"{text!r}: phase={v['phase']} calls={[c['purpose'] for c in calls]}")
      for c in calls:
          print(f"    {c['purpose']}: {c['response']}")
      print(f"    last blocks: {[(b['kind'], b.get('asks') or b.get('code')) for b in last]}")
      time.sleep(2)
  ```
