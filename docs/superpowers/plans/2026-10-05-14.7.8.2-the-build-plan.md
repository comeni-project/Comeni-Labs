# 14.7.8.2 The build plan — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a pure `plan_of(blueprint, declared) → BuildPlan` in `mendel-authoring`: for every step of
a resolved pipeline, in the blueprint's order, its card (does, why, makes, check) and what it needs
from the person (nothing, a fact, a choice), plus the wrap-up and `waits(plan, pacing)`.

**Architecture:** ports and adapters. `mendel-authoring` (pure) owns `Blueprint`, `committed` and
the plan, and reads the registry only through two narrow `Protocol`s in `ports.py`; `mendel-api`
adapts its loaded layers to them and re-exports what moved, as it already does for the protocol's
vocabulary. The resolver starts recording which facts a rule lacked (`ProducerDecision.unknown`),
so "needs a fact" is read off a typed field, never parsed out of prose. Nothing calls `plan_of`
yet: part 3 (14.7.8.3) wires it into stage ④.

**Tech Stack:** Python 3.12+, pydantic 2, pytest, Alembic (offline DDL test), uv workspace.

**Spec:** `docs/superpowers/specs/2026-10-04-the-consultant-build-design.md` §4 (revised
2026-10-05), with §1, §2, §5, §9, §10 touched by the same revision. Issue #136.

## Global Constraints

- `mendel-authoring` imports only `collections`, `collections.abc`, `dataclasses`, `enum`,
  `typing`, `pydantic`, `comeni_core`, `mendel_authoring` (`tests/guards/test_purity.py`). **No
  `json`, `re`, `hashlib`, `mendel_resolver`, `mendel_api`.**
- Every new model: `model_config = ConfigDict(extra="forbid", frozen=True)`.
- Card text is used **as written**: no rewording, no invented text; a missing source leaves the
  field out (`None` or empty), never a placeholder.
- `pipeline.yml` stays byte-identical wherever `unknown` is empty (`exclude_if`).
- Diagnostics only through `coded()`; this plan adds none.
- Run Python tests from the repository root. Read `tests/README.md` before adding a test file.
- A loop is not an assertion: assert a collection is non-empty before looping over it.
- After touching `router.py`: `make verify`, not only `make check`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; work on
  `living-pipeline-design`.

## Review Focus

1. **A tier-4 decision a person already answered** (`human_override` set) must need nothing, or
   the walk re-asks a settled question. Pinned in Task 4.
2. **A contract whose tool has no `tool.yml`**: *does* is left out, not invented. Pinned in Task 3.
3. **A contract with two outputs in one family** (`alignment.bam`, `alignment.bai`): *makes* says
   the family once. Pinned in Task 3.
4. **The Pacing setting's third option, `ask`**, is a question the shell asks first, not a pacing:
   `Pacing("ask")` must refuse rather than quietly mean one of the two. Pinned in Task 6.
5. **A blueprint stored before this plan** (it holds `"mode"`) must still load after the migration,
   and an empty blueprint (no steps) gives an empty plan, not a crash. Pinned in Tasks 2 and 6.

```python
"""blueprint without mode — a stored blueprint loses the key nothing read

`Blueprint` moved into `mendel-authoring` in 14.7.8.2 without `mode`: every Build/Spawn branch
reads the session row's `mode`, never the blueprint's. The model forbids extra keys, so a stored
blueprint still holding it would fail to load; this removes it once, in SQL, rather than leaving
a validator that drops it on every load forever.

Revision ID: e5f1a9c3b7d2
Revises: c9e4b2d71a38
Create Date: 2026-10-05

"""

from collections.abc import Sequence

from alembic import op

revision: str = "e5f1a9c3b7d2"
down_revision: str | None = "c9e4b2d71a38"
branch_labels: str | Sequence[str] | None = None
depends_on: str | Sequence[str] | None = None


def upgrade() -> None:
    op.execute(
        "UPDATE pipeline_authoring_session "
        "SET blueprint = (blueprint::jsonb - 'mode')::json "
        "WHERE blueprint::jsonb ? 'mode'"
    )


def downgrade() -> None:
    # Every blueprint ever stored was resolved under Build or Spawn; the row's own `mode` says
    # which, so the downgrade copies it back rather than guessing.
    op.execute(
        "UPDATE pipeline_authoring_session "
        "SET blueprint = (blueprint::jsonb || jsonb_build_object('mode', mode))::json "
        "WHERE blueprint::jsonb <> '{}'::jsonb AND NOT blueprint::jsonb ? 'mode'"
    )
```

```python
"""A step's card: what it does, why it is here, what it makes, and what to check.

Every field comes from declared data or from the resolver's own record, **used as written**: no
model rewords it (spec §2, option a) and a missing source leaves the field out rather than
filling it. Each line says where it came from — `curated` (declared, approved data) or `engine`
(the resolver's record) — so the marks part 4 draws have something to read.
"""

from enum import StrEnum

from comeni_core.artifact.pipeline import Step, Why
from comeni_core.declared.families import family_of
from comeni_core.plan.tiers import Tier
from pydantic import BaseModel, ConfigDict

from mendel_authoring.ports import Declared

OPEN_STEP = "no rule could decide which tool fills this step"


class Source(StrEnum):
    ENGINE = "engine"
    CURATED = "curated"


class Said(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    text: str
    source: Source


class Brief(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    does: Said | None = None
    why: list[Said]
    makes: list[Said]
    check: list[Said] = []


def tool_of(contract_id: str) -> str:
    """`nf-core/star/align@1.11.0` → `nf-core/star`: the key `tool.yml` is declared under."""
    return "/".join(contract_id.split("@", 1)[0].split("/")[:2])


def family_said(type_id: str, declared: Declared) -> Said | None:
    """A type in its family's words; types carry no description of their own."""
    described = declared.family(family_of(type_id))
    return Said(text=described, source=Source.CURATED) if described else None


def brief_of(step: Step, declared: Declared) -> Brief:
    described = declared.tool(tool_of(step.module.contract_id))
    return Brief(
        does=Said(text=described, source=Source.CURATED) if described else None,
        why=_why(step.why),
        makes=_unique(
            family_said(type_id, declared) for type_id in declared.outputs(step.module.contract_id)
        ),
        check=_unique(_checks(step)),
    )


def _why(why: Why) -> list[Said]:
    said = [Said(text=why.reason, source=Source.ENGINE)]
    if why.axis_reason:
        said.append(Said(text=why.axis_reason, source=Source.ENGINE))
    return said


def _checks(step: Step):
    """Tier 3: each premise's own sentence. Tier 4: the open question. Tiers 1–2: nothing."""
    for why, name in [(step.why, None), *((s.why, s.name) for s in step.settings)]:
        if why.tier is Tier.DATA_PROFILED:
            for premise in why.premise:
                yield Said(text=premise.prose(), source=Source.ENGINE)
        elif why.tier is Tier.AMBIGUOUS:
            text = OPEN_STEP if name is None else f"no rule decided {name}"
            yield Said(text=text, source=Source.ENGINE)


def _unique(said) -> list[Said]:
    """In order, each line once, `None` dropped."""
    seen: list[Said] = []
    for line in said:
        if line is not None and line not in seen:
            seen.append(line)
    return seen
```

```python
"""What a step needs from the person before it is placed.

- **A fact**, when a rule would decide the step and its premise is unknown (#174): the resolver
  recorded the facts in `ProducerDecision.unknown`. The tools still travel with it, so *choose a
  tool instead* is possible.
- **A choice**, when a decision on the step — its tool or a setting — is tier 4 and waits on no
  fact. Candidates are the resolver's own, never authored.
- **Nothing**, otherwise; a question a person already answered is not asked again.
"""

from collections.abc import Sequence
from enum import StrEnum

from comeni_core.artifact.pipeline import Step
from comeni_core.plan.decision import DecisionRecord, ProducerDecision
from comeni_core.plan.tiers import Tier
from comeni_core.spell.marks import ParamValue
from pydantic import BaseModel, ConfigDict

from mendel_authoring.brief import tool_of
from mendel_authoring.ports import Declared


class NeedKind(StrEnum):
    NOTHING = "nothing"
    FACT = "fact"
    CHOICE = "choice"


class Candidate(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    value: ParamValue
    does: str | None = None
    """For a tool, its declared description; nothing for a setting's value."""


class Choice(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    key: str
    candidates: list[Candidate]


class Need(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    kind: NeedKind
    facts: list[str] = []
    choices: list[Choice] = []


def decisions_of(step: Step, decisions: Sequence[DecisionRecord]) -> list[DecisionRecord]:
    """The decisions about this step: its producer question (matched on the contract chosen, as
    `committed` matches it — a contract appears at most once in a pipeline, A97), and every
    per-step record keyed `<node>.<subject>`."""
    found: list[DecisionRecord] = []
    for record in decisions:
        if isinstance(record, ProducerDecision):
            if record.chosen == step.module.contract_id:
                found.append(record)
        elif record.key.split(".", 1)[0] == step.id:
            found.append(record)
    return found


def need_of(step: Step, decisions: Sequence[DecisionRecord], declared: Declared) -> Need:
    open_ = [
        record
        for record in decisions_of(step, decisions)
        if record.tier is Tier.AMBIGUOUS and record.human_override is None
    ]
    if not open_:
        return Need(kind=NeedKind.NOTHING)
    facts = sorted(
        {fact for r in open_ if isinstance(r, ProducerDecision) for fact in r.unknown}
    )
    return Need(
        kind=NeedKind.FACT if facts else NeedKind.CHOICE,
        facts=facts,
        choices=[
            Choice(key=r.key, candidates=[_candidate(r, value, declared) for value in r.candidates])
            for r in open_
        ],
    )


def _candidate(record: DecisionRecord, value: ParamValue, declared: Declared) -> Candidate:
    if isinstance(record, ProducerDecision):
        return Candidate(value=value, does=declared.tool(tool_of(str(value))))
    return Candidate(value=value)
```

```python
"""The build's last card: what you'll get, what you need to run it, and who decided what."""

from collections import Counter

from pydantic import BaseModel, ConfigDict

from mendel_authoring.blueprint import Blueprint
from mendel_authoring.brief import Said, family_said
from mendel_authoring.ports import Declared


class Item(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    id: str
    what: Said | None = None


class Count(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    tier: int
    source: str
    count: int


class WrapUp(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    gets: list[Item]
    """The goal's wanted types."""
    inputs: list[Item]
    """The pipeline's input channels, by the parameter a run sets."""
    unset: list[str]
    """`<step>.<setting>` for every setting with no value, left to the run."""
    decided: list[Count]
    """Every step's selection and every setting, by tier and source, sorted."""


def wrap_up(blueprint: Blueprint, declared: Declared) -> WrapUp:
    pipeline = blueprint.pipeline
    tally = Counter(
        (int(why.tier), why.source.value)
        for step in pipeline.steps
        for why in [step.why, *(setting.why for setting in step.settings)]
    )
    return WrapUp(
        gets=[Item(id=t, what=family_said(t, declared)) for t in pipeline.goal.want],
        inputs=[
            Item(id=f"params.{channel.param}", what=family_said(channel.type_id, declared))
            for channel in pipeline.channels
        ],
        unset=[
            f"{step.id}.{setting.name}"
            for step in pipeline.steps
            for setting in step.settings
            if setting.value is None
        ],
        decided=[
            Count(tier=tier, source=source, count=n) for (tier, source), n in sorted(tally.items())
        ],
    )
```

```python
"""The build plan: the content of the walk, from a resolved blueprint, with no model.

One entry per step **in the blueprint's order** — the layout's, so every step comes after its
inputs for any pipeline — each with its card and what it needs; then the wrap-up. Recomputed
whole after a fact is answered and the blueprint re-resolved: the plan holds no history, and
which steps the person already accepted is the draft's. Same blueprint, same plan.
"""

from pydantic import BaseModel, ConfigDict

from mendel_authoring.blueprint import Blueprint
from mendel_authoring.brief import Brief, brief_of
from mendel_authoring.needs import Need, NeedKind, need_of
from mendel_authoring.ports import Declared
from mendel_authoring.wrapup import WrapUp, wrap_up


class PlannedStep(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    node: str
    contract: str
    brief: Brief
    need: Need


class BuildPlan(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    steps: list[PlannedStep]
    wrap_up: WrapUp

    def needing(self) -> list[PlannedStep]:
        """The steps that need a fact or a choice; the overview counts these."""
        return [step for step in self.steps if step.need.kind is not NeedKind.NOTHING]


def plan_of(blueprint: Blueprint, declared: Declared) -> BuildPlan:
    decisions = blueprint.pipeline.decisions
    steps = []
    for node in blueprint.order:
        step = blueprint.step(node)
        steps.append(
            PlannedStep(
                node=node,
                contract=step.module.contract_id,
                brief=brief_of(step, declared),
                need=need_of(step, decisions, declared),
            )
        )
    return BuildPlan(steps=steps, wrap_up=wrap_up(blueprint, declared))
```

- [x] **Step 4: Write `pacing.py`**

```python
"""How the walk paces itself: at every step together, or only where the person is needed.

The values are the Pacing setting's option ids (`comeni_core.settings.catalogue.PACING`). Its
third option, `ask`, is not a pacing: the shell asks the question and passes the answer here.
"""

from enum import StrEnum

from mendel_authoring.plan import BuildPlan


class Pacing(StrEnum):
    TOGETHER = "together"
    STOP_WHERE_NEEDED = "stop_where_needed"


def waits(plan: BuildPlan, pacing: Pacing) -> list[str]:
    """The steps the walk stops at; the shell places the rest at once."""
    if pacing is Pacing.TOGETHER:
        return [step.node for step in plan.steps]
    return [step.node for step in plan.needing()]
```
