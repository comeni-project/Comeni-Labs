# 14.7.8.3b Stage ④ — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** after *that's right*, the build walks the pipeline in the blueprint's order on the build
plan of part 2: an overview count, the Pacing fork, each step placed or stopped on (a fact, a
choice, a registry gap under the Dev fork, or *continue*), and the wrap-up; `Mode`, Build/Spawn
and the old step proposals gone.

**Architecture:** the protocol's stage ④ is redrawn with two forks (Pacing, Dev mode) from 3a.
The shell's `stages/building.py` gets one handler per new acting node; the build plan (`plan_of`,
`waits`, `gaps_of`) decides what each step needs. The dispatcher passes the interpreter a settings
snapshot resolved through the installation. The browser keeps its existing block kinds: a step is
a `StepProposal` carrying its brief, need and gaps; a fact is a `Question` on the gap card.

**Tech Stack:** Python 3.12+, pydantic 2, FastAPI, SQLAlchemy + Alembic, pytest; React 19 + TS,
vitest.

**Spec:** `docs/superpowers/specs/2026-10-04-the-consultant-build-design.md` §13 (with §13.6's
amendments), on §4 (the build plan) and §12 (forks). Issues #136, #252, #117.

## Review Focus

1. **A step that needs a fact under Dev off** must stop on the fact, not be routed around as a
   gap: the need is decided **before** the gaps (a correction to §13.2's table, which put gaps
   first). Pinned in Task 4.
2. **A fact answered *not sure*** must not ask again: the step then asks as a choice. Pinned in
   Task 4.
3. **A pipeline whose steps are all quiet under *stop where needed*** (the read length known) must
   run from `step` to `wrap` in one entry, not trip the interpreter's 64-node cycle limit. Pinned
   in Task 4: the protocol has no `step → step` arrow (pure), and scenario 1 under *stop where
   needed* reaches `wrap` (shell). A pipeline over 64 steps is not built here; the arrow's absence
   is what makes length irrelevant.
4. **A Pacing pinned in `.env`** (`COMENI_BUILD_PACING`) must win over the menu's stored value, and
   a value the declaration no longer lists must fall back to the default, not refuse the session.
   Pinned in Task 4.
5. **The browser after Mode is gone**: a home page with no Build/Spawn choice still starts a
   session, and an old `mode` in a request body is refused clearly, not silently. Pinned in Task 3.

```python
"""Registry gaps (spec §13.3): what a step's declared data lacks, and the file that would fix it.

Computed always; the Dev fork decides whether a person sees them. A gap is never a guess: each is
read off the pipeline's own record or the registry's declarations.
"""

from enum import StrEnum

from comeni_core.artifact.pipeline import Pipeline, Step
from comeni_core.plan.decision import ParamDecision
from pydantic import BaseModel, ConfigDict

from mendel_authoring.brief import tool_of
from mendel_authoring.ports import Declared


class GapKind(StrEnum):
    NO_DOMAIN = "no_domain"
    NO_DESCRIPTION = "no_description"
    UNVERIFIED = "unverified"


class Gap(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    kind: GapKind
    subject: str
    """The setting, tool or contract the gap is about."""
    fix: str
    """The repository path to edit."""


def no_domain(record) -> bool:
    """A tier-4 setting the resolver could offer no values for: its candidates are `[None]`."""
    return isinstance(record, ParamDecision) and list(record.candidates) == [None]


def _contract_file(contract_id: str) -> str:
    return f"registry/tools/{contract_id.split('@', 1)[0]}/contract.yml"


def gaps_of(step: Step, pipeline: Pipeline, declared: Declared) -> list[Gap]:
    contract = step.module.contract_id
    found: list[Gap] = []
    for record in pipeline.decisions:
        if no_domain(record) and record.key.split(".", 1)[0] == step.id:
            found.append(Gap(kind=GapKind.NO_DOMAIN, subject=record.subject,
                             fix=_contract_file(contract)))
    tool = tool_of(contract)
    if declared.tool(tool) is None:
        found.append(Gap(kind=GapKind.NO_DESCRIPTION, subject=tool,
                         fix=f"registry/tools/{tool}/tool.yml"))
    if contract in pipeline.registry.unverified:
        found.append(Gap(kind=GapKind.UNVERIFIED, subject=contract,
                         fix=_contract_file(contract)))
    return found
```

def _plan(row) -> tuple[bp.Blueprint, BuildPlan]:
    blueprint = bp.Blueprint.model_validate(row.blueprint)
    return blueprint, plan_of(blueprint, declared.of(registry.stack()))


def step_payload(blueprint, planned: PlannedStep, present: frozenset[str]) -> dict:
    """The stored payload offering one step: the card a person reads, and the options it allows.

    A choice's options are the producer decision's candidates (spec §13.6), never the candidate
    service's; every other step offers only `keep`."""
    step = blueprint.step(planned.node)
    producer = next((c for c in planned.need.choices if c.key.startswith("producer:")), None)
    others = [str(c.value) for c in producer.candidates if c.value != planned.contract] if producer else []
    minted = {f"alt_{i}": contract for i, contract in enumerate(others, start=1)}
    block = StepProposal(
        id=f"step-{planned.node}",
        node=planned.node,
        contract=planned.contract,
        reason=step.why.reason,
        tier=int(step.why.tier),
        alternatives=[Option(id=k, label=v) for k, v in minted.items()],
        brief=planned.brief,
        need=planned.need,
        gaps=planned.gaps,
    )
    here = set(present) | {planned.node}
    wires = [
        e.model_dump(mode="json")
        for e in edges_touching(blueprint, planned.node)
        if e.from_node in here and e.to_node in here
    ]
    return {
        "node": planned.node,
        "block": block.model_dump(mode="json"),
        "options": {bp.KEEP: planned.contract, **minted},
        "edges": wires,
    }

def _offer(db, row, blueprint, planned) -> str:
    draft = db.get(PipelineDraft, row.draft_id)
    present = frozenset(n.id for n in DraftGraph.model_validate(draft.graph).nodes)
    proposal_id = _id()
    db.add(PipelineAuthoringProposal(
        id=proposal_id, session_id=row.id, turn_id=None, kind=STEP,
        payload=step_payload(blueprint, planned, present), state=ProposalState.PENDING.value,
        chosen_option=None, by=None, draft_revision=draft.revision, created_at=_now(),
        settled_at=None,
    ))
    db.flush()
    return proposal_id


def _place(db, row, blueprint, planned) -> None:
    """Place a step that does not wait: offered and accepted by the engine in one go, so the
    history keeps its card, and the cursor moves on."""
    proposal = db.get(PipelineAuthoringProposal, _offer(db, row, blueprint, planned))
    draft = db.get(PipelineDraft, row.draft_id)
    commit_step(db, proposal, draft, blueprint, planned.node, option=bp.KEEP, by="engine",
                registry=registry.stack().registry)
    proposal.state, proposal.by, proposal.settled_at = ProposalState.ACCEPTED.value, "engine", _now()
    row.cursor = row.cursor + 1


def _open_facts(row) -> set[str]:
    return {f["subject"] for f in row.facts or [] if f.get("source") == FactSource.OPEN.value}


@handles("step")
def step(ctx: Ctx) -> str:
    """The walk (spec §13.6): place every step that does not wait, in this one entry, and leave on
    the first stop. **The need is decided before the gaps** (Review Focus 1): a step that needs a
    fact stops on the fact whatever Dev mode says."""
    with session_scope() as db:
        row = db.get(PipelineAuthoringSession, ctx.session_id)
        blueprint, plan = _plan(row)
        stops = set(waits(plan, Pacing(row.pacing or Pacing.TOGETHER.value)))
        while row.cursor < len(plan.steps):
            planned = plan.steps[row.cursor]
            need = planned.need
            if need.kind is NeedKind.FACT and not set(need.facts) <= _open_facts(row):
                offer_fact(db, row, next(f for f in need.facts if f not in _open_facts(row)))
                return "needs_fact"
            if need.kind is not NeedKind.NOTHING and any(
                c.key.startswith("producer:") for c in need.choices
            ):
                _offer(db, row, blueprint, planned)
                return "needs_choice"
            if planned.gaps:
                return "a_gap"
            if planned.node in stops or need.kind is not NeedKind.NOTHING:
                _offer(db, row, blueprint, planned)
                return "held"
            _place(db, row, blueprint, planned)
        return "none_left"

def offer_fact(db, row, subject: str) -> None:
    """The fact-first card: gathering's own question for `subject`, without *upload* (spec
    §13.6), answered through `AnswerGap`."""
    from mendel_api.services import gaps as gap_rules
    from mendel_api.stages import gathering

    stack = registry.stack()
    facts = [Fact.model_validate(f) for f in row.facts or []]
    gap = gap_rules.Gap(kind=FactKind.MEASUREMENT, subject=subject,
                        why="a rule needs it to choose this step's tool")
    options = {k: v for k, v in gathering._gap_options(gap, stack, facts).items()
               if k != gathering.UPLOAD}
    question = gathering._gap_question(gap, options, stack, row.row_version)
    db.add(PipelineAuthoringProposal(
        id=_id(), session_id=row.id, turn_id=None, kind=gathering.GAP,
        payload={"subject": subject, "kind": FactKind.MEASUREMENT.value, "why": gap.why,
                 "options": options, "block": question.model_dump(mode="json")},
        state=ProposalState.PENDING.value, chosen_option=None, by=None,
        draft_revision=db.get(PipelineDraft, row.draft_id).revision, created_at=_now(),
        settled_at=None,
    ))
    db.flush()


@handles("overview")
def overview(ctx: Ctx) -> None:
    with session_scope() as db:
        _, plan = _plan(db.get(PipelineAuthoringSession, ctx.session_id))
    total, needing = len(plan.steps), len(plan.needing())
    text = f"{total} step{'s' * (total != 1)}; " + (

    ])
    return None
