# 14.7.4 part 6 — Types chosen by family — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task by task, in one hand. Tick each `- [ ]` as it completes; deviations go in the
> execution record.

**Goal:** The first call no longer shows a model every type. It picks a family, from a short
declared list, then sees every type of that family, whole, and picks the type. The number of
types a call reads is bounded by family size, however large the registry grows.

**Architecture:** Families become a declared registry kind (`declares: family`), loaded and
stacked like roles, and a type whose family is not declared fails to load (`MD0316`). The first
call becomes two builder calls in the same job: `builder.family.v1` (families, the
acknowledgement, or a question when none fits) and `builder.goal.v7` (the chosen families' types,
held to them by part 5's allowed lists). A `family` node precedes `read_goal` in the protocol
object, and the diagram is regenerated. `MENDEL_FAMILY_STEP_FROM` switches the step so #198 can
compare one step with two.

**Tech stack:** Python 3.12, Pydantic 2, the registry submodule (`comeni-registry`), pytest,
Vitest.

**Spec:** [`docs/superpowers/specs/2026-09-29-reply-formats-and-families-design.md`](../specs/2026-09-29-reply-formats-and-families-design.md) §7.
**Issue:** #194 under 14.7.4 (#180). **Depends on:** plan 14.7.4.5 (`choices=` on `_call`).

## Correction to the spec, for the operator's review

**The acknowledgement cannot show before step 2.** Spec §7 says *got it shows sooner*. A turn is
answered once (`authoring.answer(session_id, seq, …)` with one revision), so step 1's `ack` lands
with step 2's result, and the person waits for both calls (step 1 adds ~2–4 s on a small model).
Showing it earlier would mean answering a turn twice, which is a change to the turn model and not
in this plan. The ack still comes from step 1, because that call reads the person's words
closest; the timing claim is withdrawn in the spec's execution notes.

## Global constraints

- **The vocabulary stays closed** (invariant 7): a type whose family is not declared fails to
  load, naming the type and the family.
- **Each family is shown whole.** Step 2 shows every type of each chosen family, and the prompt
  says it is the whole family.
- **The allowed list for a call is exactly what that call shows** (part 5's rule).
- **Every step has a way out**: step 1 can answer no family and ask; step 2 keeps `questions`.
- **No new `AiPoint`**: step 1 is a second id-choosing call inside goal extraction; recorded as a
  loosening in `authoring-protocol.md`.
- **The registry is a submodule**: family files are committed in `../comeni-registry` on a branch,
  and `registry/` is moved to that commit. **Pushing either is the operator's call.**
- **Run each check in its own call; commit in a separate call.**

## Review focus

1. **A type contributed by a tool directory** (`registry/tools/nf-core/star` declares
   `genome.index.star`): its family (`genome`) must be declared, or the stack fails to load.
   Task 6.2.
2. **Measurement types** (`measurement.paired`, derived, never in a file): the `measurement`
   family must cover them, and the check must run after `with_measurements`. Task 6.2.
3. **A lab overlay declaring a family the base already has**: it replaces the description, as any
   stacked kind does, and records a displacement. Task 6.1.
4. **Step 1 answers `families: []` with no `unclear`**: the person sees the engine's own question,
   never an empty turn. Task 6.4.
5. **Step 1 names a family, step 2 finds nothing that fits**: step 2's `questions` carry it and the
   session waits in `understanding`, as today. Task 6.4.

    stack = registry.stack()
    ack, families = None, None
    if len(stack.vocabulary.types) >= settings.family_step_from:
        chosen = authoring_ai.choose_families(
            request, stack=stack, client=_client(), session_id=session_id

        if not chosen.admitted:
            _refused(session_id, seq, context, chosen)

            return
    outcome = authoring_ai.understand(
