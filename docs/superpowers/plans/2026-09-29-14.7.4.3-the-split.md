# 14.7.4 part 3 — The split: prompts as `[system, user]` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task by task, in one hand. Tick each `- [ ]` as it completes; deviations go in the
> execution record.

**Goal:** Every builder model call sends a byte-identical, cacheable fixed part first (the system
message) and only the per-call part after it (the user message), and the second timing run shows
what that bought.

**Architecture:** `comeni_ai` gains a two-part send: `Client.chat(system, user, shape)` and
`choose_one(…, system=…)`; the transport sends messages; Anthropic models get `cache_control`
markers on the system blocks. A builder template carries a divider line, `<!-- then, per call
-->`; `PromptTemplate.render_split` returns `(system, user)`. New template versions put the
most-shared text first (the invariant block, then the vocabulary, then the prompt's own
instructions, then the schema) and end the user part with one fixed line asking for JSON only —
the weak-model lesson in `comeni_ai.client._prompt` (*the instruction has to be the last thing
read*) kept in a cache-friendly form.

**Tech stack:** Python 3.12, LiteLLM, Pydantic.

**Spec:** [`docs/superpowers/specs/2026-09-29-the-consultants-words-design.md`](../specs/2026-09-29-the-consultants-words-design.md) §6 *The split*.
**Issues:** #183 (and #185's second timing run) under 14.7.4 (#180). Runs after part 2.

## Global constraints

- **The system part is byte-identical across sessions** — no id, timestamp, or unordered set
  above the divider. A test holds every builder template to it.
- **The forge's one-string path is untouched** (`Client.generate`, `Client.respond`).
- **A prompt change is a new version file**; the old ones join `prompts.RETIRED`.
- **`last_prompt` stays one string** (system, a blank line, user) so `prompt_digest` still covers
  everything sent.
- **Recorded replies in tests, never a live model.** Each check in its own call before a commit.

## Rulings made while planning

- **Version numbers:** splitting the goal prompt with its content unchanged makes it
  `builder.goal.v5`; part 4's goal with the acknowledgement becomes **v6** (the spec says v5 has
  the acknowledgement). Cost if wrong: one version number.
- **Cache markers:** a `<!-- cache -->` line in a template splits the system part into blocks;
  each block ends with a `cache_control` marker **only for `anthropic/` models** — LiteLLM
  passes the field through to providers that may reject it, and OpenAI and Ollama cache a
  prefix without markers.

def test_every_builder_prompt_has_one_divider_and_a_system_part_identical_across_sessions():
    """#183: caching pays only if everything above the divider is byte-identical."""
    assert prompts.TEMPLATES
    for prompt_id in prompts.TEMPLATES:
