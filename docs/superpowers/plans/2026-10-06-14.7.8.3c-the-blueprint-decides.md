# 14.7.8.3c — The blueprint decides, the walk reviews — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (CLAUDE.md: execute
> plans yourself; subagents review only). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every decision in stage ④ — a tool swap or a fact — is an amendment to the goal; the
blueprint is `resolve(goal)`; the draft is a projection of the blueprint; any step can be swapped
for a compatible tool, offered as a whole pipeline with its difference.

**Architecture:** The router decides through a chain of small deciders that return a `Choice` or an
open question (`Asked`) and never write to the plan; a goal-level `ProducerPin` wraps the chain.
`mendel-authoring` gains pure `Site`-keyed amendments, `BlueprintDiff`, `alternatives_of`,
`drafted` (the projection) and `stops(step, policy)`. The shell's stage ④ is redrawn on one
waiting `card` node and one acting `amend` node, and `stages/building.py` splits in three.

**Tech Stack:** Python 3.14 (uv workspace), pydantic, FastAPI, SQLAlchemy/Alembic, React 19 + TS,
vitest.

**Spec:** `docs/superpowers/specs/2026-10-04-the-consultant-build-design.md` §14 (read §12–§13 for
the forks, pacing and gaps it keeps).

## Review Focus

1. **A swap that drags steps with it** (STAR → HISAT2): the draft has HISAT2's index and aligner,
   no STAR step, and no edge from a step that is not in the blueprint — the orphan class, as a
   property test (Task 4) and a shell test (Task 7).
2. **A pin equal to the engine's pick** must change nothing — same bytes, same tier, same source
   (Task 2).
3. **A pin at a tie** must not ask the resolver (no model call, no second record): exactly one
   `ProducerDecision`, `human_override` set (Task 2).
4. **A card answered twice / a stale card** (double click, two tabs): the second `Amend` or
   `SettleStep` is refused with MI0203, nothing re-resolved (Task 7).
5. **A long quiet walk** (100 gap steps, *stop where needed*, Dev off) reaches the wrap-up inside
   the interpreter's node limit (Task 6).

## Corrections to the spec, made while planning

- **The canvas's *added by your choice* marking moves to part 5** (the cards and the walk). The
  amendment's receipt names what it added and removed, and the walk's next card is the added step,
  so the person sees it; marking the canvas needs a stored *last change*, which nothing else needs.
- **`SetFact` carries the rebuilt profile**, not one measured entry: `DataProfile` is built only by
  `MeasurementRegistry.profile_of` (invariant 15's construction guard), so the shell builds the
  new profile at the edge and `apply` swaps it in. Every `apply(goal)` stays pure and uniform.
- **`Choice.pinned`** is a sentence (*rule condition: …* or *your choice*), replacing the old
  `pinned_by` dict, because its one reader is `UnroutablePinError`'s message.

```python
@dataclass(frozen=True)
class Choice:
    """Which contract fills a site, at which tier, why, and on whose say-so. Was a six-tuple."""

    contract: ModuleContract
    tier: Tier
    reason: str
    source: ValueSource = ValueSource.RESOLVER
    pinned: str | None = None
    """Who pinned it, as `UnroutablePinError` says it: a rule's condition, or a person."""
    pin: Pin | None = None


@dataclass(frozen=True)
class Asked:
    """A tier-4 site, its question not yet answered: a tie (invariant 8) or a rule that cannot
    apply (invariant 4). Answering is `_answer`'s, so deciding never writes to the plan."""

    question: ProducerAsked
    tied: list[ModuleContract]
    summary: str
    unknown: tuple[str, ...] = ()


@dataclass(frozen=True)
class _Here:
    type_id: str
    states: frozenset[str]
    candidates: list[ModuleContract]
    ordered: list[ModuleContract]
    roles: list[str]
    rules: RuleTable | None
    premises: dict[str, object]
    rule_pin: Pin | None

    def rank(self, contract: ModuleContract) -> tuple[int, int, str]:
        return (_surplus(contract, self.type_id, self.states), -contract.priority, contract.id)
```

`_here(type_id, states, candidates, *, goal, rules, premises) -> _Here` computes `roles` and
`rule_pin` exactly as `_choose` does today (keep both comments: A119 and invariant 10's sort) and
`ordered = sorted(candidates, key=rank)`. Then one function per existing branch, **moving the
existing code and comments verbatim**, each returning `None` when it does not apply:

- `_by_rule(here)` — the `pinned is not None` branch; returns
  `Choice(match[0], Tier.DATA_PROFILED, pin.reason_line(pin.row.when), pinned=f"rule condition: {pin.row.when}", pin=pin)`; `None` when the pinned contract is not a candidate (keep that comment).
- `_by_unapplied_rule(here)` — `None` unless `here.rules` and `here.rule_pin is None` and the
  `ruled` list is non-empty; returns `_asked(here, ruled, why_open=…, evidence=…, candidates=…,
  summary=…, unknown=tuple(unknown))` with today's strings.
- `_uncontested(here)` — `len(ordered) == 1` → tier 2 (keep A113's comment).
- `_exact_states(here)` — `best[0] < rank(ordered[1])[0]` → tier 1.
- `_by_priority(here)` — `best[:2] < rank(ordered[1])[:2]` → tier 2.
- `_tie(here)` — always an `Asked` (keep A125's and A128's comments).

```python
_CHAIN = (_by_rule, _by_unapplied_rule, _uncontested, _exact_states, _by_priority, _tie)


def _decide(here: _Here) -> Choice | Asked:
    """The first decider that answers. `_tie` always does, so this never falls through."""
    for decider in _CHAIN:
        decided = decider(here)
        if decided is not None:
            return decided
    raise AssertionError("_tie answers every site")
```

`_asked(here, tied, *, why_open, evidence, candidates, summary, unknown=()) -> Asked` builds the
`ProducerAsked` the way `_ask` does today. `_answer(asked, resolver) -> tuple[Choice,
ProducerDecision]` is the rest of `_ask` (resolver call, fallback, record, `how`, source) returning
the record instead of appending it. `_choose` becomes:

```python
def _choose(type_id, states, candidates, goal, rules, resolver, plan, premises) -> Choice:
    here = _here(type_id, states, candidates, goal=goal, rules=rules, premises=premises)
    decided = _decide(here)
    if isinstance(decided, Asked):
        choice, record = _answer(decided, resolver)
        plan.decisions.append(record)
        return choice
    return decided
```

```python
def _by_person(here: _Here, decided: Choice | Asked, pin: ProducerPin):
    """A person's pin (spec §14.3, §14.9): it **wraps** the chain. `None` — the engine's choice
    stands — when the pinned tool is not a candidate here (inert) or is the engine's own pick
    (a pin that agrees changes nothing). Otherwise tier 4, source person, with the engine's pick
    and its reason kept beside it, and one `ProducerDecision`; the resolver is never asked."""
    match = next((c for c in here.candidates if c.id == pin.contract), None)
    engine = decided.contract.id if isinstance(decided, Choice) else None
    if match is None or engine == pin.contract:
        return None
    if isinstance(decided, Choice):
        reason = f"you chose {pin.contract} over {engine}, which the engine picked: {decided.reason}"
        why_open = "a person chose another tool than the engine's"
        unknown: tuple[str, ...] = ()
    else:
        reason = f"you chose {pin.contract}; {decided.question.why_open}"
        why_open, unknown = decided.question.why_open, decided.unknown
    question = ProducerAsked(
        node_id=_node_id(match), subject=f"producer:{here.type_id}",
        what=f"which contract produces {here.type_id}", why_open=why_open,
        candidates=sorted(c.id for c in here.candidates), states=sorted(here.states),
    )
    record = ProducerDecision(
        key=question.key(), subject=question.subject, candidates=question.candidates,
        chosen=pin.contract, human_override=pin.contract, reason=reason, confidence=1.0,
        resolved_by="person", unknown=list(unknown),
    )
    return Choice(match, Tier.AMBIGUOUS, reason, ValueSource.HUMAN, pinned="your choice"), record
```

`diff.py`:

```python
"""What changed between two blueprints, by step id — read by an alternative's card, the
amendment's receipt and a hand edit's receipt (spec §14.9). One computation, three readers."""

from comeni_core.plan.draft import DraftGraph
from pydantic import BaseModel, ConfigDict

from mendel_authoring.blueprint import Blueprint


class BlueprintDiff(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    added: list[str] = []
    removed: list[str] = []
    swapped: list[tuple[str, str]] = []
    """Same step id, another contract: `(step id, new contract)`."""

    @property
    def empty(self) -> bool:
        return not (self.added or self.removed or self.swapped)

    def sentence(self) -> str:
        parts = []
        if self.added:
            parts.append("adds " + ", ".join(self.added))
        if self.removed:
            parts.append("removes " + ", ".join(self.removed))
        if self.swapped:
            parts.append("changes " + ", ".join(f"{n} to {c}" for n, c in self.swapped))
        return "; ".join(parts) or "changes nothing"


def _between(before: dict[str, str], order_before: list[str],
             after: dict[str, str], order_after: list[str]) -> BlueprintDiff:
    return BlueprintDiff(
        added=[n for n in order_after if n not in before],
        removed=[n for n in order_before if n not in after],
        swapped=[(n, after[n]) for n in order_after if n in before and before[n] != after[n]],
    )


def diff_of(before: Blueprint, after: Blueprint) -> BlueprintDiff:
    tools = lambda b: {s.id: s.module.contract_id for s in b.pipeline.steps}  # noqa: E731
    return _between(tools(before), before.order, tools(after), after.order)


def graph_diff(before: DraftGraph, after: DraftGraph) -> BlueprintDiff:
    tools = lambda g: {n.id: n.contract_id for n in g.nodes}  # noqa: E731
    return _between(tools(before), [n.id for n in before.nodes],
                    tools(after), [n.id for n in after.nodes])
```

`amend.py`:

```python
"""What a person (or, in part 4, a model) can change about a pipeline in the walk: each is a
frozen value applied to the goal, so the goal holds every decision and the blueprint is a function
of it (spec §14.3). A model can only send one of the amendments a card offered, by id."""

from comeni_core.goal.asked import Goal, ProducerPin
from comeni_core.goal.profile import DataProfile
from comeni_core.spell.marks import ParamValue
from pydantic import BaseModel, ConfigDict


class ChooseTool(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    pin: ProducerPin

    def apply(self, goal: Goal) -> Goal:
        kept = [p for p in goal.constraints.producers if p.site != self.pin.site]
        constraints = goal.constraints.model_copy(update={"producers": [*kept, self.pin]})
        return goal.model_copy(update={"constraints": constraints})

    def says(self) -> str:
        return f"use {self.pin.contract} to make {self.pin.site.type_id}"


class SetFact(BaseModel):
    """A fact a rule lacked. **`profile` is built by the shell** through the measurement registry
    (invariant 15: nothing else constructs a `DataProfile`), so `apply` only swaps it in."""

    model_config = ConfigDict(extra="forbid", frozen=True)

    measurement: str
    value: ParamValue
    profile: DataProfile

    def apply(self, goal: Goal) -> Goal:
        return goal.model_copy(update={"profile": self.profile})

    def says(self) -> str:
        return f"{self.measurement} is {self.value}"


Amendment = ChooseTool | SetFact
```

`alternatives.py`:

```python
"""A step's other tools, each as the whole pipeline it gives (spec §14.3): the amendment, the
difference, or why it cannot be built. Computed when the card is offered; `resolve` is a port."""

from collections.abc import Callable

from comeni_core.goal.asked import Goal, ProducerPin
from pydantic import BaseModel, ConfigDict

from mendel_authoring.amend import ChooseTool
from mendel_authoring.blueprint import Blueprint
from mendel_authoring.diff import BlueprintDiff, diff_of

Resolve = Callable[[Goal], Blueprint]


class Alternative(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    id: str
    contract: str
    amendment: ChooseTool
    diff: BlueprintDiff | None = None
    refused: str | None = None
    """Why it cannot be built from this goal — shown, never offered."""


def alternatives_of(blueprint: Blueprint, goal: Goal, node: str, candidates: list[str],
                    resolve: Resolve, refusals: tuple[type[Exception], ...]) -> list[Alternative]:
    """`refusals`: what `resolve` raises for a goal that cannot be built — the shell passes
    `(UnroutableError,)`; `mendel-authoring` does not depend on the resolver."""
    site = blueprint.sites.get(node)
    if site is None:
        return []
    chosen = blueprint.step(node).module.contract_id
    found: list[Alternative] = []
    for contract in (c for c in candidates if c != chosen):
        amendment = ChooseTool(pin=ProducerPin(site=site, contract=contract))
        try:
            diff = diff_of(blueprint, resolve(amendment.apply(goal)))
        except refusals as refused:
            found.append(Alternative(id=f"alt_{len(found) + 1}", contract=contract,
                                     amendment=amendment, refused=str(refused)))
            continue
        if not diff.empty:
            found.append(Alternative(id=f"alt_{len(found) + 1}", contract=contract,
                                     amendment=amendment, diff=diff))
    return found
```

`draft.py`:

```python
"""The draft is a projection of the blueprint (spec §14.3): the steps the person has reviewed,
with their edges and provenance, recomputed after every amendment and every review. Nothing is
appended, so nothing is left over from an older blueprint (issue 253)."""

from comeni_core.plan.draft import DraftGraph, DraftProvenance
from pydantic import BaseModel, ConfigDict

from mendel_authoring.blueprint import Blueprint, committed
from mendel_authoring.ports import Contracts


class Reviewed(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)

    node: str
    by: str


def kept(blueprint: Blueprint, reviewed: list[Reviewed]) -> list[Reviewed]:
    """A reviewed step the new blueprint no longer has leaves the set."""
    return [r for r in reviewed if r.node in blueprint.order]


def next_step(blueprint: Blueprint, reviewed: list[Reviewed]) -> str | None:
    seen = {r.node for r in reviewed}
    return next((n for n in blueprint.order if n not in seen), None)


def drafted(blueprint, reviewed, profile, registry: Contracts) -> tuple[DraftGraph, DraftProvenance]:
    by = {r.node: r.by for r in kept(blueprint, reviewed)}
    graph, provenance = DraftGraph(profile=profile), DraftProvenance()
    for node in (n for n in blueprint.order if n in by):
        graph, provenance = committed(blueprint, graph, provenance, node, by=by[node],
                                      registry=registry)
    return graph, provenance

@handles("step")
def step(ctx: Ctx) -> str:
    """Place every step that does not stop, in this one entry (any length: issue 258), then
    project the draft once; leave on the first stop or at the end."""
    with session_scope() as db:
        row = db.get(PipelineAuthoringSession, ctx.session_id)
        blueprint, plan = _plan(row)
        policy = Policy.model_validate(row.policy)
        reviewed = [Reviewed.model_validate(r) for r in row.reviewed or []]
        by_node = {p.node: p for p in plan.steps}
        outcome = "none_left"
        while (node := next_step(blueprint, reviewed)) is not None:
            stop = stops(by_node[node], policy)
            if stop is not None:
                cards.offer(db, row, blueprint, plan, node, stop)
                outcome = "stops"
                break
            reviewed.append(Reviewed(node=node, by="engine"))
        row.reviewed = [r.model_dump(mode="json") for r in reviewed]
        amending.project(db, row, blueprint)
        return outcome

@records(c.Amend)
def amend(ctx: Ctx, cmd: c.Amend) -> StepOutcome:
    """One of the card's offered amendments, by id (spec §14.5): checked, applied to the goal,
    the step it decided marked reviewed, then `amend` re-resolves and projects."""
    with session_scope() as db:
        proposal = _pending_step(db, cmd.proposal_id)          # MI0203 / MI0205
        row = db.get(PipelineAuthoringSession, proposal.session_id)
        ctx.session_id = row.id
        _registry_unmoved(row)                                  # MI0206, as settle
        amendment = _offered(proposal, cmd.option, cmd.value, row)   # MI0205 / MI0208
        goal = amendment.apply(Goal.model_validate(row.goal))
        row.goal = goal.model_dump(mode="json")
        if isinstance(amendment, ChooseTool):
            row.reviewed = [*(row.reviewed or []), Reviewed(node=proposal.payload["node"], by=cmd.by)
                            .model_dump(mode="json")]
        proposal.state, proposal.by = ProposalState.ACCEPTED.value, cmd.by
        proposal.chosen_option, proposal.settled_at = cmd.option, _now()
        session.check(row.id, Command.AMEND.value)
    session.take(ctx, Command.AMEND.value)
    return _outcome(ctx)


@handles("amend")
def amend_node(ctx: Ctx) -> str:
    with session_scope() as db:
        row = db.get(PipelineAuthoringSession, ctx.session_id)
        goal, before = Goal.model_validate(row.goal), bp.Blueprint.model_validate(row.blueprint)
    try:
        fresh, _ = bp.resolve(goal)
    except UnroutableError as exc:
        ctx.raised = exc
        return "cant_build"
    with session_scope() as db:
        row = db.get(PipelineAuthoringSession, ctx.session_id)
        row.blueprint, row.registry_digest = fresh.model_dump(mode="json"), fresh.registry
        row.reviewed = [r.model_dump(mode="json") for r in
                        kept(fresh, [Reviewed.model_validate(r) for r in row.reviewed or []])]
        project(db, row, fresh)
        _rows.engine_turn(ctx.session_id, lambda seq: [Receipt(
            id=f"amend-{seq}", summary=diff_of(before, fresh).sentence(),
            revision=db.get(PipelineDraft, row.draft_id).revision, by="person",
        ).model_dump(mode="json")])
    return "amended"


def project(db, row, blueprint) -> None:
    """The draft from the blueprint and the reviewed steps — and the goal with it (issue 254)."""
    goal = Goal.model_validate(row.goal)
    draft = db.get(PipelineDraft, row.draft_id)
    graph, provenance = drafted(blueprint, [Reviewed.model_validate(r) for r in row.reviewed or []],
                                goal.profile, registry.stack().registry)
    if graph.model_dump(mode="json") != draft.graph or draft.goal != row.goal:
        draft.graph, draft.provenance = graph.model_dump(mode="json"), provenance.model_dump(mode="json")
        draft.goal = row.goal
        draft.revision, draft.updated_at = draft.revision + 1, _now()
```
