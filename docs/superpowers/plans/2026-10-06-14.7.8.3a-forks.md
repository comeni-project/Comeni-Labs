# 14.7.8.3a Forks — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the protocol can declare a **fork**: a node whose outgoing edges are the cases of a
pluggable subject (a setting today), which the pure interpreter takes from a snapshot the shell
passes in, checked for coverage when the protocol loads, and drawn as a diamond.

**Architecture:** a new pure module `mendel_authoring/forks.py` holds `Snapshot`, the `Subject`
base (the strategy) and its first kind, `SettingSubject`, made from a setting's own declaration.
`Node` gains `fork`, `Edge` gains `case`; `Protocol`'s load-time validator gains the coverage
rules; `interpret.run` gains a `snapshot` and one branch. Nothing in the product changes: the real
protocol gets its first fork in 3b.

**Tech Stack:** Python 3.12+, pydantic 2, pytest.

**Spec:** `docs/superpowers/specs/2026-10-04-the-consultant-build-design.md` §12. Issues #136, #252.

## Review Focus

1. **A toggle's value arrives as a bool** (`True`/`False`) from the settings store, not `"on"`:
   `SettingSubject.value` must map it, or every Dev fork in 3b takes no edge. Pinned in Task 1.
2. **A setting absent from the snapshot** (never set, so the store holds nothing) must take the
   setting's declared default, not refuse. Pinned in Task 1.
3. **A fork's case edges carry `on=None`**: the existing "more than one way straight through"
   rule and `_one_way_on` must not misread them as several unnamed ways on. Pinned in Task 2.
4. **A choice option marked `designed`** (greyed in the menu) is still an option a fork must cover,
   since a stored value could hold it once built. Pinned in Task 1.
5. **A run that enters a fork with no snapshot passed** (today's shell, until 3b wires it) must
   take the default rather than crash. Pinned in Task 3.

```python
"""What a fork switches on (spec §12): a **subject**, its **cases**, and a **snapshot** to read.

A fork is a node whose outgoing edges are the cases of a subject; the interpreter asks the
subject which case the snapshot is in and takes that edge, so a path that depends on a setting is
drawn in the diagram rather than decided by an `if` in a handler. **The subject is the strategy**:
a setting today; a parameter, a fact or a property of the plan later, each one more subclass and
no change to the interpreter. Pure: the snapshot is plain data the shell builds.
"""

from comeni_core.settings.declare import Kind, Setting
from pydantic import BaseModel, ConfigDict, JsonValue

DEFAULT = "*"
"""The case an open subject's fallback edge names. No option can be `*`."""


class _Frozen(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")


class Snapshot(_Frozen):
    """What a fork may read, as plain data. A field per kind of subject, as they arrive."""

    settings: dict[str, JsonValue] = {}


class Subject(_Frozen):
    """What a fork switches on. Subclass it; the interpreter only calls these two methods."""

    title: str
    """What the diamond says."""

    def options(self) -> frozenset[str] | None:
        """The closed set of cases, or `None` for an open domain (which then needs `DEFAULT`)."""
        raise NotImplementedError

    def value(self, snapshot: Snapshot) -> str:
        """The case `snapshot` is in."""
        raise NotImplementedError


class SettingSubject(Subject):
    """A setting, its cases read off its own declaration so they cannot drift from the menu."""

    key: str
    cases: frozenset[str] | None
    default: JsonValue = None

    @classmethod
    def of(cls, setting: Setting, title: str | None = None) -> "SettingSubject":
        if setting.kind is Kind.CHOICE:
            cases: frozenset[str] | None = frozenset(o.value for o in setting.options)
        elif setting.kind is Kind.TOGGLE:
            cases = frozenset({"on", "off"})
        else:
            cases = None
        return cls(
            key=setting.key,
            title=title or setting.label,
            cases=cases,
            default=setting.default,
        )

    def options(self) -> frozenset[str] | None:
        return self.cases

    def value(self, snapshot: Snapshot) -> str:
        raw = snapshot.settings.get(self.key, self.default)
        if isinstance(raw, bool):
            return "on" if raw else "off"
        if raw is None and self.cases == {"on", "off"}:
            return "off"
        return str(raw)
```

def _case(protocol: Protocol, node: Node, snapshot: Snapshot) -> Edge:
    """The edge out of fork `node` for the case `snapshot` is in, or its `DEFAULT`."""
    value = node.fork.value(snapshot)
    out = {e.case: e for e in protocol.edges if e.built and e.source == node.id}

    if found is None:

            coded("MI0216", f"fork {node.id!r} has no edge for {value!r}, and no default")
        )
    return found
