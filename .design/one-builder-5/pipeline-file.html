The difference

  • A keeps the file unbroken and gives the reason room for the value, its citation and the actions. It's closest to the board and to the step view. On a phone the reason becomes a sheet from the bottom.
  • B uses the full width for the file and reads like an annotated file. But the YAML gets interrupted, and long citations wrap awkwardly.
  • Either way, Compile it runs the existing emission with visible progress, and its tabs show main.nf and nextflow.config, read-only.
