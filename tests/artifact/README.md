# Saved pipeline tests

Shared CLI builders and file-edit helpers are in `support.pipeline`. Compatibility fixtures stay in `tests/fixtures/`; they are not regenerated by the code under test.

| Behavior | File | Focus |
|---|---|---|
| Serialization and regeneration | [test_pipeline_serialization.py](test_pipeline_serialization.py) | CLI writes, reads, emitted digests and missing files. |
| Parameter wiring | [test_pipeline_wiring.py](test_pipeline_wiring.py) | Resolved settings reach the emitted Nextflow. |
| Decision provenance | [test_pipeline_provenance.py](test_pipeline_provenance.py) | Reasons, overrides, premises and supplying layers survive serialization. |
| Invalid artifacts | [test_pipeline_validation.py](test_pipeline_validation.py) | Malformed inputs and unsafe values are refused. |
| Gate verdicts | [test_pipeline_gate_verdicts.py](test_pipeline_gate_verdicts.py) | Re-emission preserves valid verdicts and invalidates stale ones. |
| Historical formats | [test_pipeline_compatibility.py](test_pipeline_compatibility.py) | Archived documents and schema version compatibility. |
| Model totality | [test_pipeline_totality.py](test_pipeline_totality.py) | Artifact model coverage. |
| Upgrade | [test_upgrade.py](test_upgrade.py) | Re-resolution, changes and retained decisions. |
| Publication | [test_publish.py](test_publish.py) | Publication checks and payload behavior. |
| Model attribution | [test_ai_provenance.py](test_ai_provenance.py) | AI provenance in saved artifacts. |
| Pins and lockfiles | [test_lockfile.py](test_lockfile.py) | Dependency pinning and reproducibility. |

Run `uv run pytest tests/artifact -q` from the repository root.
See the [test index](../README.md) for shared setup and execution requirements.
