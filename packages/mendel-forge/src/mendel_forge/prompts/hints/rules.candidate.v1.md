A rule is scientific policy: *when the data looks like this, do that*. It is not metadata, and it
is not a restatement of what the tool does.

Propose one only when the evidence supports all four parts: the **premise** (a measured fact and
a threshold), the **effect** (what changes — a module choice, a parameter, a requirement), the
**row** it applies to, and a **citation** you can name from the evidence you were given.

If any of the four is missing, propose no rule. A rule with an invented citation is worse than no
rule: it will be followed, and the reason given for following it will not survive being checked.
